# PZwiki 가구 전체 목록

확인일: 2026-11-03. Furniture에서 연결된 12개 분류 페이지의 48개 표를 Cloud Browser로 열람해 추출했다.

**총 1,268개 행 / 서로 다른 이름 1,188개 / 서로 다른 연결 URL 1,049개.** 이 세 수는 집계 기준이 다르며 게임 내 가구 종류 수를 뜻하지 않는다.

## 범위와 읽는 방법

- 이 목록은 12개 분류 페이지에 등재된 모든 표의 데이터 행이다. 개별 상세 문서 전체를 조사한 결과는 아니다.
- 색상·형태·variant 표기와 동명 행을 그대로 보존했다. 원문에서 별도 행으로 나누지 않은 변형이나 방향별 스프라이트를 추가하지 않았다.
- 대분류·소분류는 한국어로 옮겼고, 개별 가구 이름은 원문을 보존했다. 공식 한국어 게임 번역과 대조하지 않았다.
- CSV에는 운반부담(Encumbrance), 타일 크기, 제작표면, 침대품질·수납용량(해당 분류), 회수·분해 기술과 도구, 문서·이미지 URL을 담았다. 운반부담은 kg 단위 실중량으로 바꾸지 않았다.
- 빈 값은 원문 공란이다. 불가·없음으로 추정하지 않았다. 병합된 불가 안내 셀은 해당 기술·도구 두 열에 같은 문구를 보존했다.
- 목록ID는 이번 추출의 행 식별자이며 게임 타일 ID가 아니다. 이미지 URL은 참조 주소로, 이미지 파일을 내려받거나 외형을 시각 검증하지 않았다.
- 대부분의 분류 페이지는 42.8.0 기준 안내 및 B42 unstable에서 일부 타일을 의도적으로 제외했다는 안내를 표시한다. Plumbing은 42.20.4 기준 안내다. 최신 게임 전체 가구를 보장하는 목록으로 사용하면 안 된다.
- Plants의 Streetname Sign, 일부 동음이의어 링크 등 원문의 의심스러운 분류·명칭도 임의 수정하지 않았다.
