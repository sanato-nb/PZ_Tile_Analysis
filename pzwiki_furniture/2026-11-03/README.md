# PZwiki 가구 목록 — 2026-11-03

Furniture에서 연결된 12개 분류 페이지의 48개 표를 Cloud Browser로 열람해 정리한 자료입니다.

- 전체 1,268행, 서로 다른 이름 1,188개, 서로 다른 연결 URL 1,049개입니다. 집계 기준이 다르며 게임 가구 종류 수와 동일하지 않습니다.
- 위키 목록 전체를 수집한 것이며 게임 전체 가구의 완전성을 보장하지 않습니다. 대부분의 원문 페이지에는 B42에서 일부 타일이 제외됐다는 안내가 있습니다.
- 기존 저장소의 타일 DB와 아직 대조·병합하지 않았습니다. 공식 Local ID 매핑이나 이미지 정체 인증 자료가 아닙니다.

## 다른 채팅에서 읽는 순서

1. 이 README로 범위와 주의사항을 확인합니다.
2. [전체 목록 정리본](furniture_catalog.md)에서 분류별 이름을 확인합니다.
3. [CSV 1,268행](furniture_1268.csv)을 실제 데이터 처리에 사용합니다. UTF-8 BOM 인코딩입니다.
4. 원문 표 구조와 값은 [추출 JSON](source_tables.json)으로 대조합니다.
5. 일괄 다운로드는 [ZIP](furniture_bundle.zip)을 사용합니다. ZIP 내부 파일은 원래 한국어 파일명입니다.

## 보존한 정보

분류, 소분류, 영어 가구명, 동명 순번, 운반부담, 타일 크기, 제작표면, 침대품질·수납용량(해당 분류), 회수·분해 기술과 도구, 개별 문서 URL, 분류 페이지 URL, 이미지 URL을 포함합니다.

- 같은 이름이나 같은 URL이라는 이유만으로 행을 합치지 않았습니다. variant 표기를 보존했습니다.
- 한국어 분류는 정리를 위한 번역이고 개별 가구명은 원문입니다. 공식 한국어 게임 번역과 대조하지 않았습니다.
- `PZW-0001` 등의 목록ID는 이 자료의 행 ID이며 게임 타일 ID가 아닙니다.
- 빈 값은 원문 공란입니다. 이미지 URL을 수집했지만 이미지 파일 다운로드·시각 검수는 하지 않았습니다.
- 개별 상세 문서 전체를 읽은 결과가 아니라 분류 페이지 표의 추출 결과입니다.
- 원문의 분류 오류 가능성, 동음이의어 링크, 동일 이름 반복을 임의로 수정하지 않았습니다.
