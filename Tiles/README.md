# 원본 타일셋 이미지

이 폴더에는 프로젝트 좀보이드 타일 분석에 사용하는 원본 타일 이미지와 관련 타일셋 자료를 보관합니다.

- 분석 시 원본 PNG의 실제 픽셀을 확인합니다.
- TMX의 위치·레이어 정보와 함께 A/B/C/D 이미지를 생성해 비교합니다.
- 타일셋 파일명만 보고 물체의 정체를 확정하지 않습니다.
- PNG와 TMX의 Local ID 대응 및 TileZed 공식 렌더 정합성은 **별도 검증 대상**입니다.
- 원본 이미지·타일셋 정의 파일은 삭제하거나 덮어쓰지 않습니다.

최신 분석 현황은 [프로젝트 상태](../PROJECT_STATE.json)를 참고하세요. 분석 기록과 복원용 데이터베이스는 `analysis/`에 별도로 저장됩니다.
