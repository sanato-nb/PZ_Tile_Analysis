# 목표 — 타일 정체를 이미지로 알아내기

프로젝트 좀보이드 B42 TMX의 개별 타일이 실제로 **무슨 물체인지, 그 물체의 어느 부분인지** 파악하는 것이 최우선이다. 단순히 이름을 비슷하게 붙이는 작업이 아니다.

원본 PNG의 스프라이트를 TMX 좌표와 같은 레이어의 주변 타일로 조합한 장면을 실제로 본 다음 정체 후보를 기록한다. 가구는 여러 칸이 합쳐져 하나의 사물이 될 수 있고, 벽은 평면/모서리/개구부로 쪼개지며, 피·흙·오염은 독립 물체가 아닌 겹침 이미지일 수 있다. 잘못된 확정은 향후 마인크래프트 맵 재현 오류로 이어진다.

**완료 기준:** 분석 대상 고유 타일 전체에 대해 시각 관찰 또는 사유가 기록된 보류를 남기고, Local ID/PNG 대응과 장면 렌더링을 검증해 사물 정체 또는 부품 역할을 구분한다. 보류가 남아 있는 동안 정체 정의 100%를 주장하지 않는다.

현재의 작업 기준과 과거 보고 수치는 `../PROJECT_STATE.json`을 읽는다.
