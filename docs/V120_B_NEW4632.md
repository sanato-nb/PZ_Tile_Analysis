# v120 — 신규 타일 4,632종의 B단계(TM X 원본 배치 5×5 주변) 완료

## 실제 수행

v119에서 대표 A 원본 이미지를 지정한 신규 타일 **4,632종**을 대상으로, `26_43.tmx`부터 `37_49.tmx`까지 **84개 실제 TMX** 전체를 재탐색했다. 각 `(tileset_name, local_id)`의 실제 배치 하나를 찾고, 동일 층의 주변 **5×5칸**을 각 레이어 순서에 맞춰 아이소메트릭으로 조립한 **B 장면 4,632장**을 생성했다. 이전에 검수한 **5,409종은 새로운 대상에서 제외**하고 주변 배치 복원을 위해 필요한 경우에만 이전 A 후보를 재사용했다.

| 검증 항목 | 결과 |
|---|---:|
| 원본 TMX 검사 | 84개, 원본 SHA-256 대조 통과 |
| 신규 고유 타일 배치 좌표 | 4,632개 |
| B 5×5 원본 주변 장면 | **4,632장** |
| 장면 접촉시트 | 58장 (각 최대 80개) |
| B 이미지 ZIP 샤드 | 12개 (WebP 4,632장, SHA/CRC 검사 통과) |
| 주변 스프라이트 일부 미조립 | 8개 B장면, 누락된 그리기 9건 |
| 맵 바깥으로 5×5 확장 불가 | 48개 B장면 |
| 출력 캔버스에서 개별 스프라이트 잘림 | **23,823회 그리기** (B장면 수 아님) |
| 검증된 공식 TileZed/Local ID 매핑 | **0종** |
| C(대상 타일 제거), D(다른 위치) | 미생성 |

B 결과물은 **현실의 TMX 배치에서 출처가 확인된 조립 이미지**지만 **TileZed 공식 렌더가 아니고**, 대상 타일이 건축물에 가려질 수도 있다. PNG 추출은 v119/v117의 가설적 A 격자에 의존한다. 장면에 있는 주변 물체가 모두 정확한 ID로 검증됐다는 뜻이 아니다.

## 품질과 다음 단계

이미지 직접 판독 표본: 광고판, 전선/전봇대, 음식점, 주택·욕실·상점 등 **4개 접촉시트 표본**을 AI가 직접 열어 확인했다. **58장 전수 AI 판독 또는 4,632개 사물 정체 확인으로 주장하지 않는다.**

일부 B는 대상이 주변 건물에 가려져 직접 보이지 않고, JUMBO 나무는 큰 PNG 캔버스에서 잘릴 수 있다. 이 때문에 C에서 **해당 위치·층·레이어의 raw GID 한 건만** 제거하고 B와 C를 비교해야 한다. 긴 전선이나 나무는 필요하면 15×15 이상의 확대 장면을 구성한다. 원본 B가 가려져 있다고 해서 투명 또는 존재하지 않는 타일이라고 판정하지 않는다.

**기존 v116 통합 SQLite, v119 A 원본, 기존 5,409키·사용자 수동 제외 14키, 원본 PNG/TMX 모두 변경하지 않았다.** 이 v120 결과는 독립된 B 증거 계보이다.
