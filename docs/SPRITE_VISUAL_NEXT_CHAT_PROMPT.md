# 다음 이미지 분석을 시작하는 요청문 (v242)

이 요청문은 **새 채팅/다른 모델/로컬 비전 분석기**에도 동일한 검사 기준을 적용하기 위한 재사용 지침입니다. 프로젝트 데이터를 새로 학습시킨 모델 자체를 뜻하지 않습니다.

## 바로 사용할 시작 지시

> **프로젝트 좀보이드 B42 타일 이미지 분석을 진행해.** 먼저 GitHub `sanato-nb/PZ_Tile_Analysis`의 최신 `main`, `docs/SPRITE_VISUAL_ANALYSIS_PLAYBOOK.md`, `docs/SPRITE_ANALYSIS_QUICK_REFERENCE.md`, `docs/SPRITE_REVIEW_RECORD_TEMPLATE.json`, `docs/ANALYSIS_RULES.md`, `docs/CURRENT_STATUS.md`를 읽어. 이력상 v240은 전체10,042키, 활성9,587키, 제외455키다. 시작할 때 최신 GitHub 상태를 재확인하고 보류439/수동 제외16은 내 새 지시 없이 활성화하지 마.
>
> **핵심 순서:** 정확한 PNG·Local ID·RGBA 크롭을 출처와 함께 고정하고, 타일명/과거 후보와 B/C 완성 화면을 가린 채 **A 원본 이미지를 먼저 직접 판독**해 색·실루엣·투명도·접합선·방향 단서를 적어. 완성 사물인지, 여러 타일 중 상판/측면/다리/모서리/벽/기둥인지, 바닥·혈흔/오염·그림자 같은 overlay인지 별도로 판단해. A 관찰 사실과 기능·정체 가설을 혼합하지 마.
>
> 그다음 진짜 TMX의 동일 키/GID/층/레이어/x/y로 원래 B를 렌더하고 그 **배치 한 개만** 제거한 C와 비교해. 상위 벽·지붕·가구는 다른 셀에서도 앞을 가릴 수 있으니 B−C=0/미세 변화만으로 A가 비어 있거나 투명하거나 벽에 가렸다고 확정하지 마. 원인 가림을 시험할 땐 B/C 원본을 보존하고 가림 요소만 끈 별도 `DIAGNOSTIC` 렌더를 사용해. 다른 실제 TMX 사용 위치는 **B 재검증**, 공식적으로 같은 키에 대응하는 다른 A를 B와 같은 위치에 대입할 수 있을 때에만 **D 실험**이라고 불러.
>
> 같은 사물이 여러 조각으로 나뉘면 각 A의 역할을 별도로 기록하고 실제 TMX 이웃 좌표/레이어로 연결 그래프를 만들어. 이소메트릭 **화면 방향**, TMX **월드 방향**, 물체의 **앞/뒤**를 구분해. 색이 붉다는 이유만으로 혈흔, 검다는 이유만으로 구멍 같은 단정을 하지 마.
>
> 각 키에 `원본 A 직접 관찰 사실`, `부품/연결 후보`, `방향 및 근거`, `오버레이 여부`, `B/C 원래 관찰`, `가림/누락 원인과 검증 여부`, `불확실성`, `다음 검사`, `출처 경로와 해시`를 별도로 저장해. 진행률은 이미지 로딩·육안 관찰·잠정 후보·물리 DB 통합·공식 인증을 나눠 보고해. 공식 mapping/TileZed/정체 인증은 증거 없는 한 0 유지. 원본 PNG/TMX/사용자 수동 판정/이전 DB는 삭제·덮어쓰지 마. 작업 완료 후 **실제 생성·검증한** 파일·GitHub 커밋·PR만 보고해.

## 자료가 없는 상황에서의 행동

PNG가 없으면 타일셋명으로 사실을 추론해 확정하지 않는다. 정확한 key/GID/크롭을 찾을 수 없으면 `source_missing`, 원래 B 화면이 가려져 있으면 `not_exposed_cause_unknown`, 이웃 소스가 빠지면 `missing_neighbor_source`라고 설명한다. **추정값은 추정값, 원본에서 직접 본 사실은 사실**로 구분한다.

## 판정 예시 양식

```text
source_key:
A(원본에서 실제로 보이는 것):
A(안 보이거나 확정할 수 없는 것):
표현 역할(독립/부품/구조/오버레이/그림자/불명):
연결될 수 있는 조각/실제 TMX 상대 좌표:
방향(A 화면 / TMX 맵 / 물체 앞면):
B 원래 위치·가시성:
C 정확히 하나 제거 결과:
가림·지도끝·누락소스 진단 상태:
D 실행 여부(검증된 동일키 공식 대체 A 확인):
잠정 정체 후보와 근거:
남은 의문 / 다음 최선의 검증:
원본 PNG/출처·해시:
상태: 직접관찰 / 잠정후보 / 보류 / 공식 매핑 / 최종 인증
```

**완료 보고는 새로 실제 관찰·렌더·해시한 범위만 세어야 한다.** 이미 있는 시트나 이전 CSV를 읽은 것을 이번 회차의 새 육안 판독/새 렌더와 구별한다.
