# 다음 타일 이미지를 볼 때 1분 판정표 (v242)

**먼저 [전체 작업 매뉴얼](SPRITE_VISUAL_ANALYSIS_PLAYBOOK.md)을 기준으로 삼습니다.** 이 표는 빠르게 방향을 잡기 위한 것이며 정체 확정표가 아닙니다.

## 관찰을 시작하는 순서

**키/GID/크롭 확인 → A 원본 픽셀 단독 확인 → A에 보이는 형태만 적기 → 단일/분할/구조/오버레이 후보 분류 → 실제 B 배치 → 한 배치 제거 C → 방향·가림·연결/추가 테스트 → 잠정/보류 기록.**

| A에서 보이는 특징 | 자주 했던 잘못된 추정 | 우선 의심할 범주 | 다음 증거 |
|---|---|---|---|
| 길고 가는 세로 선 1~3줄 | 완성된 벽, 기둥, 울타리 | 좁은 벽 옆면 / 틈새 가림 / 기둥 / 장식선 | 연결된 상단선·바닥 접점·이웃 같은 계열/층 |
| 두 면이 꺾여 만나는 작은 판 | 독립 상자 | 코너 / 접합부 / 벽-벽 연결 | 인접한 양 방향 패널·이소메트릭 투영 |
| 얇고 넓은 마름모 평판 | 완성된 책상·지붕 | 상판 / 바닥 / 천장·지붕 조각 | 다리, 옆면, 기와·무늬, TMX 실제 배치 |
| 앞면/측면 다른 음영 | 별도 물체 | 동일 사물의 방향별 변형 | 앞면 손잡이, 짝 스프라이트, 맵 회전·GID 플래그 |
| 직선단·잘린 두께·부분 기둥 | 사물 전체 | 여러 타일로 이어지는 부품 | 같은 패턴의 실제 이웃과 상대 좌표 |
| 불규칙한 붉은 픽셀 얼룩 | 혈흔 확정 | blood-like / 페인트 / 손상 / 장식 decal | 알파, 뒤 표면, 재질 유사성. **색만으로 인증 금지** |
| 얼룩진 회갈색 투명 패치 | 새로운 지형이나 고체 | dirt-like / shadow / surface overlay | RGBA, 바닥 위 합성, 반복 타일 |
| 검은 그림자/빈 영역 | 깊은 구멍·우물 | 그림자 / 개구부 / 알파 결손 | A alpha와 이웃 연결·벽 단면 구별 |
| 원형 둘레와 위쪽 걸이 | 화덕 확정 | 화덕/우물형 등 구조 후보 | A 형태 우선, 다른 실제 B/C와 이웃 |
| 계단 모양의 단차·수직 지주 | 단순 목재 프레임 | 계단·발판·높이 있는 플랫폼 | 발판 수와 지주를 A에서 직접 기술 |
| B의 큰 사물이 보임 | A가 사물 전체 | A 단일 조각+완성 장면을 혼동한 것 | 원본 A 단독 실루엣 확인 |
| B에서는 대상이 안 보임 | A가 투명 또는 빈 타일 | 벽·상층·지붕·가구 가림 / 렌더 문제 | 원본 A 비투명 픽셀, 층별 진단용 렌더 |
| C를 만들었는데 B−C=0 | 사물이 없음 / 벽 가림 확정 | 원인 미확인 | GID/오프셋·PNG 누락·레이어·진단 마스킹 |
| B−C 극소 양수 | 해당 물체 정체가 확인됨 | 일부 가장자리·다른 물체에 가림 | 변화 픽셀 위치와 A 실루엣 비교 |
| B의 5×5가 맵 밖으로 잘림 | 타일 자체가 미확인 | B 촬영 위치만 부적합 | 같은 키의 **다른 실제 TMX 사용 위치** 찾기 |
| 이웃 PNG 하나가 없음 | 그 타일이 의미 없음 | 입력 소스 결손 | 정확한 누락 key 회복 또는 다른 실제 B 위치 |

## 꼭 따로 대답해야 하는 질문 8개

1. `무슨 픽셀이 보이는가?` — A 원본 **사실**.
2. `단독 사물인가, 전체 사물의 일부인가?` — 부품/표현 역할 **가설**.
3. `어느 방향으로 놓였는가?` — A 화면 방향과 실제 TMX 방향 **구별**.
4. `다른 타일과 연결되는가?` — 정확한 실제 좌표/레이어로 **연결 증거**.
5. `고체인가, 흔적·그림자인가?` — alpha와 합성 **진단**.
6. `B에서는 보이는가?` — 원래 B 노출 여부, 가림 원인은 **독립 실험**.
7. `C에서 한 배치를 빼면 바뀌는가?` — B−C, **원인/정체 확정과 별개**.
8. `무엇을 아직 모르는가?` — 보류 이유와 가장 효과적인 **다음 검사 하나**.

## 수행 단계별 기록

| 실제 작업 | 허용되는 표현 | 허용되지 않는 표현 |
|---|---|---|
| A PNG 경로만 찾음 | 원본 경로 색인됨 | 이미지 직접 관찰 완료 |
| A 이미지를 직접 보았음 | A의 외곽 형태 관찰 | 완성 사물/기능 확정 |
| B/C 시트가 과거에 존재 | 과거 증거 재사용 | 이번에 원본 B/C 새 렌더 완료 |
| B−C 픽셀 변화가 있음 | 목표 배치 제거가 화면을 바꿈 | 공식 타일 명칭/매핑 인증 |
| 다른 B 장면에서 노출됨 | 해당 키의 다른 실제 배치 증거 | 사용자 정의 D 수행 |
| 진단용 벽 숨김으로 A가 드러남 | 그 벽·레이어의 가림 증거 확보 | 원래 B가 그 상태였음 |
| 이름·부품 역할로 잠정 추론 | `provisional_candidate` | `certified` |
| 정확한 공식 ID/명칭 근거 없음 | `held` 또는 잠정 | 확실하다고 표시 |
