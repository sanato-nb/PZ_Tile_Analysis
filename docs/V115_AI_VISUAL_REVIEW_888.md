# v115 · AI 직접 시각 재검수 (888종)

## 목표와 근거

최신 v113 SQLite에서 **이미지는 관찰했지만 감사 가능한 물체 정체 후보가 없던 888종**을 대상으로 했다. 이 888종은 신규 타일 4,633종과 구분한다. 저장한 `review/v115_model_visual/sheet_000.jpg`부터 `sheet_073.jpg`까지 **74장의 실물 A1/A2/B/C/D 비교판을 AI가 직접 읽었다.** `review/v115_model_visual/INDEX.csv`에서 888개 키와 각 검수판의 슬롯 번호를 추적할 수 있다.

### 정확성 주의사항

- 원본 A 후보 2개는 TMX 선언 격자와 TileZed 텍스트 격자로 **별도 추출한 잠정 크롭**이며, 공식 Local ID 대응을 증명한 것이 아니다.
- AI 모델이 74장을 실제 눈으로 검토했지만, 결과 중 870종은 상당수가 '정확한 물건·방향·독립 부품 기능'보다 **물체의 종류·부품 계열**을 적은 것이다. 882종을 최종 정체 인증 또는 전부 세부 식별 완료로 표현하지 말 것.
- 모든 v115 행의 `mapping_verified`, `tilezed_verified`, `final_certified`는 **0**이다.
- v113 누적 이미지 관찰 **5,400/5,409종**, 기존 감사 가능 잠정 후보 **4,512종**, 기존 미관찰 9종과 사용자 제외 8종은 변경하지 않으며 v115 후보 882종은 별도 계보로 보존한다.
- 원본 PNG/TMX, 과거 수동 검수 80종, 이전 SQLite 버전의 테이블을 삭제·변경하지 않음.
