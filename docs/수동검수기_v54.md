## 수동 검수기 기능
1. 검색·타일셋 필터·사용 횟수 정렬·미검수/후보/보류/정체 모름/원본 의심 구분.
2. A 원본 픽셀, B 같은 높이 5×5 TMX 조립, C 지정 배치 제거, D 다른 TMX 위치의 실제 기록을 브라우저 Canvas로 필요할 때 생성.
3. 관찰 특징·추론 후보·부품 역할·확신 정도·보류 사유 기록.
4. 로컬 자동 저장(브라우저에 따라 제한 가능), **JSON 백업/복구**, UTF-8 BOM CSV 내보내기, CSV 불러오기.
