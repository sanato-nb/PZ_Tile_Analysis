## C. 작업 이력과 대화 원문을 혼동하지 말 것

- 실제 작업 이력 162개 PR 중 #1–90은 기존 v131 패키지 `02_GitHub_PR_1-90_목록.md`, #91–162는 `docs/PR_91-162_2026-10-29.md`.
- `docs/HANDOFF.md`와 `AGENTS.md`에는 v196부터 누적 버전 기록이 역순으로 보존돼 있다. GitHub 문서가 원본 대화의 축어록은 아니다.
- **과거 대화 일부는 ChatGPT의 축약/생략된 구간으로 원문 확보 불가.** v131 전체 인수인계 압축에 과거 원문 텍스트 5개와 복원 가능한 발화 합본, 당시 사용자의 결정 검증표, 원본 첨부가 들어 있다. 이를 보완 자료로 사용하고 원문이 없는 부분은 인용문 형태로 꾸미지 않는다.
- 필요 시 사용자가 ChatGPT 설정에서 공식 대화 내보내기를 하여 실제 전체 축어록을 더할 수 있다. 지금 생성한 인수인계서는 사용 가능한 원문과 GitHub 근거가 확인된 부분에 한정한다.
