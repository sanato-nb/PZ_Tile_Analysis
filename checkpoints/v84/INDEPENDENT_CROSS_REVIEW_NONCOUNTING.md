## 경위와 수량

v83 통합 DB(관찰 3,497종)의 미관찰 대기열에서 **12종**을 선정하여 GitHub 원본 PNG·TMX의 A/B/C/D 비교판 **12개를 실제 열어 직접 관찰**했다. A 원본 크롭, B 동일 층 5×5, C 선택 배치 한 건 제거, D 다른 실제 위치이며 `checkpoints/v84_preview/`의 이미지와 메타데이터를 근거로 했다.

그 사이 별도 검수 작업이 `main`에 **v84 신규 92종(후보 74, 보류 18)**을 먼저 병합했다. 독립 검수한 12종의 키는 그 92종에 **모두 포함**되어 있으며 B-C 픽셀 변화도 12/12 일치한다. 따라서 **이 문서는 신규 관찰 수에 0종을 추가하며, 기존 `PROJECT_STATE.json`·통합 SQLite·기존 v84 `observations.tsv`를 변경하지 않는다.** 중복·충돌 방지를 위해 이전 PR #28은 병합하지 않고 닫았다.

별도 의견의 원문은 `checkpoints/v84/INDEPENDENT_SECOND_OPINION_12_NONCOUNTING.tsv`에 보존한다. 각 행은 `count_in_progress=0`이며 원래 증거 경로, 원본 해시, 위치, 후보/보류 상태와 독립 판독 문장을 유지한다.

### 의미 있는 해석 차이

- `fixtures_stairs_01/33`: 독립 검수에서는 **목재 계단 4단 분할 조각**, main v84에서는 **하단 3단**으로 기록했다. 원본의 최상단 가는 부분을 디딤판으로 셀지, 상단 연결부로 볼지 구분이 필요하다. 두 가설을 모두 유지하고 계단의 전체 조립 및 TileZed 대조 전까지 단수 확정은 보류한다.
- `blends_street_01/82` 및 `/83`: 독립 검수는 **평지붕 표면에서 관찰되는 회색 삼각 질감 조각**, main v84는 **도로 표면을 잇는 삼각 아스팔트 블렌드**로 적었다. B·D의 실제 사용 장면은 지붕으로 보이나 이것만으로 원래 용도가 지붕 전용인지, 범용 아스팔트 블렌드인지 결정할 수 없다. **사용 장소(지붕)와 타일의 기능(재질 경계)을 분리**하여 재검증해야 한다.
- `furniture_storage_01/57`, `/58`: 독립 검수는 **문 1개·하단 서랍 2개**를 강조했고, main은 **옷장/장식장**이라는 상위 범주를 썼다. 대체로 양립 가능한 설명이지만 분할 부품의 방향과 서랍 수는 추가 확인 대상이다.
- `blends_street_01/72~75`: 두 계보 모두 **보류**이며 B-C 변화는 각각 328, 322, 310, 219픽셀이다. 가는 회색 선이 실제 어떤 경계를 연결하는지 분명하지 않다.
