# v110 잠정 TileZed 격자 30종 직접 시각 판독

2026-10-26, v109의 신규 48종과 겹치지 않는 v108 미관찰 51종을 조사했다. TMX 원본에서 두 번째 실제 사용 좌표가 있는 32종을 찾았고, 그중 30종의 원본 PNG를 TileZed `tiledefinitions.tiles.txt` 격자(실제 PNG 2배 치수 일치)에 맞춰 **잠정** 추출했다. 원본 PNG A, 동일 층 TMX 5×5 B, 한 배치만 제거한 C, 실제 다른 TMX 사용 위치 D를 만들었다.

**A/B/C/D 개별 JPEG 150장과 6종씩 묶은 접촉판 5장을 생성하고 접촉판 5장 모두 직접 열어 판독했다.** 30종 전부 다른 실제 TMX D를 갖고, B-C 픽셀 변화는 0보다 크다. 다른 위치가 5칸 이상 떨어지거나 다른 지도인 D는 28종, 근접 D 2종이다. 판독 PSV 30행: **잠정 후보 25종, 보류 5종**. 후보는 전부 `low`, 최종 인증 0이다.

**중요한 매핑 한계:** TMX의 `d_generic_1` 이미지 선언은 8열×11행(512×1408, 64×128 타일)이지만 TileZed 타일정의 텍스트는 16열×10행이고 실제 PNG는 2048×2560(128×256 타일)이다. `d_wallcracks_1`은 TMX 8×9, 타일정의 9×8, `f_bushes_1`은 TMX 8×14, 타일정의 16×8이다. 타일정의 격자를 이용하면 PNG와 격자 크기가 정확히 맞고 B-C 가시변화가 확인되지만, **TMX GID Local ID와 공식 TileZed 렌더 대응을 인증한 것은 아니다.** `mapping_verified=0`, `tilezed_verified=0`, `final_certified=0` 유지.

PNG 없는 2종(`e_cockspurhawthornJUMBO_1/1`, `jumbo_tree_01/0`)은 A 증거가 없어 제외했다. 나머지 19종은 실제 D가 없어 본 엄격한 관찰 대상에서 제외했다. 사용자 수동 검수 80종과 기존 모든 DB·체크포인트는 수정하지 않는다.
