# v73 독립 이미지 관찰 감사 기록 (2026-10-26)

## 검수 방식
GitHub 원본 PNG/TMX로 생성한 `checkpoints/v73_preview/`의 **20개 A/B/C/D 비교판(각 4장)**을 검수자가 실제 열어 관찰했다. 각 비교판에는 A 원본 스프라이트, B 같은 층 5×5 근사 아이소메트릭, C 동일 레이어의 단일 배치 제거, D 다른 실제 사용 위치가 들어 있다. 비교판 외 각 패널의 JPEG도 저장되어 있어 총 100장이다. 이미지 파일 존재나 기존 AI 후보만으로 판정하지 않았다.

## 검수 결과

- `fixtures_doors_01/33`: 격자창 상하 2칸, 검은 프레임, 붉은 표시가 있는 전자 키패드 출입문.

- `blends_grassoverlays_01/49,51,52,53,56,58,60,64,65,66`: 황록·누런빛 긴 풀 포기와 작은 잎 무리의 형태별 오버레이. B/C에서 일부 풀이 사라지고 D의 다른 지면 사용 장면을 확인. 식물 종(種)은 확정하지 않음.
- **보류 `blends_grassoverlays_01/57`**: A는 잎 무리지만 B-C 변화가 **423픽셀**에 그치고 울타리·수풀에 가려 개별 기여를 분리하기 어려움.
- **보류 `blends_grassoverlays_01/59`, `/61`, `/67`**: B-C 변화가 각각 **0픽셀**. A의 외형은 기록하되 배치 기여가 확인되지 않아 정체 가설은 비움.

## 제한·보존·검증
- 모든 신규 타일의 PNG 물리 높이와 TMX 선언 높이가 불일치(`height_mismatch`)하며, 공식 PNG–TMX Local ID 대응과 TileZed 렌더링은 **검증되지 않았다**. `mapping_verified=0`, `tilezed_verified=0`, `final_certified=0`.
- 이 검수는 새 이미지 관찰 기록이며 최종 사물 정체 인증이 아니다.
- 이전 원본 DB·체크포인트·사용자 수동 검수 80종 및 재검수 계보를 수정하거나 합산하지 않는다.
- 원본 PNG/TMX SHA-256, TMX 좌표·층·레이어·raw GID, B-C 픽셀 변화, 누락 주변 타일 수는 `observations.tsv` 및 `EVIDENCE_MANIFEST.json`에 보존한다.
- 통합 SQLite의 실제 무결성·중복·복원 결과는 GitHub Actions의 별도 검증 통과 후에만 최종 보고한다.
