# 좀보이드 원본 지도 자료

이 폴더에는 프로젝트 좀보이드 B42의 원본 지도·격자 관련 자료를 보관합니다.

- 타일 위치, 건물 배치, 레이어, 높이 등을 해석할 때 참조합니다.
- 원본은 분석 자료이므로 **삭제·이름 변경·덮어쓰기하지 않습니다.**
- TMX 분석 대상 및 최신 분석 범위는 저장소 루트의 [프로젝트 상태](../PROJECT_STATE.json)에서 확인합니다.
- 변환 결과, 판독 기록, SQLite 데이터베이스는 원본과 분리하여 `analysis/` 및 `checkpoints/`에 저장합니다.

> 이 안내문은 기존 지도 원본 파일을 수정하지 않고 별도로 추가한 문서입니다.
