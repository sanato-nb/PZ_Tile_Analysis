# 로즈우드 B42 가구 목록 — PZwiki × TMX 1차 교차 대조 (2026-11-03)

## 범위와 의미

- 기준: [PZwiki furniture README](../../pzwiki_furniture/2026-11-03/README.md), 원본 `furniture_1268.csv` 전체 **1,268행**을 변경 없이 참조.
- 실제 게임 지도: `B4220.3_MapExport_256/tmx/`의 `31_43.tmx`, `31_44.tmx`, `31_45.tmx`, `31_46.tmx`, `32_43.tmx`, `32_44.tmx`, `32_45.tmx`, `32_46.tmx` (8개 파일).
- 영역은 X=7936–8447, Y=11008–12031이며, **로즈우드 주변 일부까지 포함한 작업 사각형**이지 공식 시가지 경계가 아님. 다른 TMX 및 경계 외부는 아직 조사하지 않았음.
- 위키 스프라이트 이미지 URL의 이름 `<tile_set>_<local>[_+local...].png`에서 후보 키를 추출하고, 원본 TMX `tileset.firstgid`와 GID를 교차 대조함. **PNG-원본 Local ID의 공식 일치 검증은 아직 완료하지 않음.**

**주의:** `모든 구성 타일 발견`은 같은 지역 안에서 각 ID를 발견했다는 뜻이지 한 개의 완성 가구를 조립 검증했다는 뜻이 아니다. `주변배치_참고` 역시 근접 배치 단서로서 인증 아님. `해당타일_배치기록수`는 구성 스프라이트 기록의 합으로 **가구 개체 수가 아님**. 미발견 항목도 게임 미존재가 아니라 이번 8개 TMX 내 동일 키 미검출을 뜻함.
