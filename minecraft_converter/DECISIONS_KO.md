# 사용자 확정 설계 원칙 — PZ → Minecraft 맵

아래 항목은 **설계 결정**이다. 각 항목이 모두 구현·검증되었다는 뜻이 아니다. 실제 구현 상태는 [PROJECT_STATUS_KO.md](PROJECT_STATUS_KO.md) 확인.

## 좌표·층·지형
- 프로젝트 좀보이드 1타일 = 마인크래프트 XZ 1×1블록. TMX X→마크 X, TMX Y→마크 Z; 전역 원점은 PZW로 확인.
- 층 높이 간격 4블록. 바닥 1블록 + 실내 자유 높이 3블록. 기준 지면 Y64.
- 원본 계단 3타일 + 상부 착지 1칸. 원본 확인 및 통행 테스트 없이는 임의 배치 금지.
- 도로·잔디·건물 1층 바닥은 높이 차 없이 Y64 재질로 구분.
- 상층 바닥은 TMX에서 실제 확인된 곳만 생성하고 빈 공간은 유지. 천장·지붕만 있는 곳에 바닥을 만들지 않음.
- 지면 밑 기본 채움: 흙 2블록 + 돌 5블록. 지하실/지하 구조와 충돌하면 원본을 우선하고 물리 구조 검증 전에는 파지 않음.
- 지표면에 명시적 바닥이 없는 칸은 원본 지형/지역 근거가 확인될 때만 보완. 근거 없으면 미확정 기록.
- 수역은 원본 경계 유지·실제 물 생성. 원본 수심 우선, 없으면 연못2·강3·호수5블록. 물가에서 안쪽으로 단계적 수심. 재질은 원본 우선, 없으면 강 자갈/모래, 호수 모래/진흙, 연못 진흙/흙.
- 도로는 일반 노면 기본 블록 + 차선/횡단보도/정지선만 커스텀 텍스처. 인도 경계도 단차 없이 재질로 구분.
- 바닥은 바닐라 블록을 기본, 필요한 곳만 커스텀 텍스처.

## 원본에 충실한 객체 처리
- 초기에 벽·문·창문·지붕/천장은 제외 (데이터는 보존). 울타리·담장·난간도 제외.
- 차량과 가로등·전봇대·신호등·표지판 등 도로 시설물도 첫 생성에서 제외, 정보만 보존. 오염/잔해 효과도 첫 단계 제외.
- 나무는 전용 모델을 새로 만들지 않고 바닐라 나무 블록으로 배치; 원본 줄기 좌표 보존, 주요 구조물을 침범하는 잎만 제거, 줄기 충돌은 기록.
- 스탠드·탁상 조명 등 가구형 조명은 가구 모델 또는 임시 표시. 벽등·천장등은 제외.
- 가구의 외형·배치 우선, 수납/착석/취침 기능은 원본 속성을 보존하고 추후 좀보이드 시스템 모드와 연결.
- **Codex에서 제작한 가구 모델은 그대로 사용**. 크기·색상·형태를 변환기가 임의 변경하지 않는다. 문제가 있으면 모델 자체 수정.
- 원본 부품·방향과 모델 앵커 연결, 회전 후 점유 범위 검사. 다칸 가구도 하나의 객체로 관리. 충돌은 확인된 원본 특성에 따라 임시 구분; 정확한 모델별 충돌은 후속 모드 작업.
- 모델이 없는 가구는 원본 ID·좌표·층·레이어·방향과 전체 점유 범위를 보존하며 임시 블록으로 표시, 나중에 자동 교체. 미확정 연결은 추측하지 않음.
- 원본 가구 고유 ID와 Codex 모델 연결표를 사용하고, 기존 v259 메타데이터는 후보/근거로 활용. 이름 유사성만으로 확정 금지.
- 가구가 위층 바닥과 충돌해도 모델을 자동 축소하지 않고 기록·검수.
- 변환 불가 타일 역시 원본 ID·좌표·층·레이어를 보존하고 필요 시 임시 표시.

## 월드 생성·검수·확장
- 빈(Void) 월드에서 원본 지형만 생성하는 **실제 Java 월드 파일** 방식.
- 첫 테스트는 `31_46.tmx` 전체 256×256 및 **확인된 실제 층만**. 인접 TMX와 연결하기 위한 경계 정보 저장.
- 추가 TMX는 기존 월드를 유지하고 신규 구역만 생성; 인접 구역이 추가되면 양쪽 경계 자동 재검수.
- 기존 구역 재변환은 **별도 테스트 월드**에서 검수한 다음, 해당 XZ 범위와 변환기가 관리하는 Y 범위만 보호된 방식으로 교체.
- 작업은 지형·도로 → 층별 바닥 → 계단 → 가구 순으로 나누어 단계별 검수.
- 단계별/16×16 청크별 체크포인트를 저장하고 완료·검증된 청크만 재사용. 원본/규칙 변경 시 영향 청크 무효화.
- 같은 원본/규칙/전역 좌표/시드를 쓰면 항상 같은 결과가 되도록 결정적 변환.
- 초기 바이옴은 plains 기본, 필요할 때 일부 구역별로 변경 가능.
- 초기는 몬스터/동물 자연 생성 비활성화, 낮·맑음 고정, 크리에이티브 기본. 이동·충돌 검수는 서바이벌로 전환. 정식 월드 시스템은 나중에 설정.
- 최초 스폰은 실제 지면이 있고 장애물/물/공간 문제 없는 좌표를 탐색.
- 자동 검수+게임 내 수동 검수. v259 기반 오류 시각 지도와 CSV·JSON 생성 목표.
- 공통 오류는 변환 규칙 수정, 좌표 특수 사례는 예외 규칙으로 관리. 수정 후 별도 월드 재검수.
- 좌표·층·필수 바닥·구역 침범 등 치명적 오류는 정식 반영 차단. 미확정 장식/임시 가구는 표시·기록 후 검수하여 반영 가능.
- 반드시 사용자에게 한 단계씩 설정을 계속 묻지 말 것. 현재 기준으로 개발을 진행하고 진짜 결정이 불가피할 때만 질문.

## 유보
Minecraft 정식 버전, 모드 로더 및 좀보이드 시스템 모드는 가구 모델 개발 상황을 보고 나중에 결정. **Java 1.20.1은 오직 현재 프리뷰의 임시 데이터 버전**이다.
