- 월드 설정: `B4220.3_MapExport_256/Kentucky.pzw`, `native-256`, worldOrigin `0,0`, cell `31,46`
- 범위 256×256, Minecraft X=7936..8191 / Z=11776..12031.

## 제외·미완료 (혼동 금지)
- 벽·문·창문·지붕·울타리·난간·도로 시설물·차량·오염: 1차 변환에서 의도적으로 제외 또는 시스템 결정까지 보류. 원본 기록을 잃지 않을 것.
- 도로 차선/횡단보도/표지, 정확한 재질 전체 대응, 강·호수/수심, 남은 식생/대형 나무 **45건**, 고급 식생 모델은 미완성.
- 3D 가구 모델 미연결. **유리 블록은 실제 유리 가구가 아니라 플레이스홀더**.
- 오브젝트별 부품 병합·방향·모델 기준점/충돌 검증, 전체 자동 검수 지도(v259 UI), 경계 증분 보정, 청크 체크포인트/보호된 교체는 설계 원칙이지만 아직 모두 완성된 기능은 아님.
- 게임을 사용한 실제 계단 보행 테스트/자동 충돌 검증이 완료되었다고 주장하지 말 것.

## 다음 순서 (기존 사용자 합의 유지)
1. 원본 PNG+TMX 기준 **도로 차선/표시·소규모 식생·대형 나무·지형 텍스처**부터 점진 복원. 재질 결정의 근거를 ID별로 남길 것.
2. 건물 **실제 원본 바닥**만 구현·검증. `31_46`에는 확인된 위층 바닥이 없으므로 이 구역에 억지로 층을 만들지 않는다.
3. 다른 TMX에서 계단 원본 확인 후 3칸+착지 1칸 검증. 합성 계단 시험 맵과 실제 지도는 별개.
4. Codex 가구 모델 준비 시 원본 다칸 점유·앵커·회전 기준을 따라 그대로 연결. 이상하면 모델 자체 수정.
5. 자동/수동 검수와 경계·청크 증분 갱신으로 범위 확대.
