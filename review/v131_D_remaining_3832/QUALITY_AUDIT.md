## AI가 실제 열어본 표본 시트

- `batch_0000_0319/ALT_A_B_sheet_00.jpg`: 광고판 기둥의 원래 A 대신 음료 광고 그림 조각이 들어간 사례, 통신 장치 대신 위성 접시·컴퓨터·기계가 다른 A 후보로 놓이는 사례 다수. **서로 다른 물체/다른 Local ID일 위험을 직접 시각 확인**.
- `batch_4320_4631/ALT_A_B_sheet_07.jpg`: 실내 벽·아치형 창틀·벽돌 조각에서 서로 다른 색/방향/형상의 인접 타일이 대체되어 있음. 일부는 같은 구조물 계열이어도 **원래 Local ID의 다른 A인지는 확인되지 않음**.
- 전체 모든 접촉시트를 독립 AI 개별 판독한 것은 아님. **신규 시각 정체 관찰 수 증가 0**.

## 가장 중요한 제한

**D의 이미지 생성 4,631건 완료는 원본 스프라이트가 동일한 Local ID에 정식 대응한다는 뜻이 아니다.** 4,628종은 실제로 **이웃 격자에 있는 다른 타일 ID일 수 있는 A 가설**, 3종은 **동명 PNG 변형**이지만 공식 TileZed 매핑 미검증. B−D 픽셀이 변하는 것 자체는 후보가 정답이라는 근거가 아님.

- `official_same_key_A_mapping_verified=0`, `tilezed_verified=0`, `identity_final_certified=0`.
- 원본 타일의 이름만으로 사물을 확정하거나, 빈 B−C 결과를 투명 타일로 단정하지 않는다.
- 진정한 D 단계의 의미는 **같은 타일의 다른 A 후보를 원래 B의 같은 TMX 위치에 조립해 비교하는 과정**이고, 과거 v124의 다른 TMX 두 번째 사용 위치 색인은 **별도 보조 자료**다.
- 공식 Local ID 매핑이 필요한 경우 반드시 원본 TileZed 정의와 아틀라스 분할 구조, TMX 주변 맥락을 별도 시각 검증해야 한다.
