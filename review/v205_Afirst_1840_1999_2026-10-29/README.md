이번 실제 검수는 v146에 이미 잠정 기록된 **155개 고유키**를 대상으로, 원본 A 스프라이트의 투명 픽셀을 배경 격자와 함께 먼저 직접 보고, 그 후 **과거 실제 TMX B와 목표 GID 하나만 제거한 C** 증거를 비교한 것이다.

## 확인한 원본 증거
- A 크롭: `review/v119_selected_A_new4633/sheets/SELECTED_A_023.jpg` 및 `SELECTED_A_024.jpg`. 이 160칸에 포함된 원본 A의 개별 모양을 관찰했다. 비투명 픽셀이 매우 작은 경우도 배경 투명 격자와 구별.
- B/C: `review/v121_C_diff_new4632/sheets/C_B_DIFF_023.jpg`, `C_B_DIFF_024.jpg`. C는 과거 TMX에서 해당 타일 raw GID 하나만 제거한 장면. **이번 회차에 새 TMX 파싱/렌더는 하지 않음.**
- 실제 원본 PNG 아틀라스도 `Tiles/2x/location_restaurant_spiffos_01.png`, `Tiles/2x/location_shop_fossoil_01.png`를 별도로 열어 직접 확인. `location_shop_generic_01.png`는 GitHub 도구에서 base64가 빈 문자열이라 원본 A 추출 증거 시트로 판독.
- `A_ONLY_INDIVIDUAL_155.csv`에는 **155개 A 전부의 짧은 개별 형태 문장**, `A_B_C_REAUDIT_WITH_CHANGE_COUNTS_155.csv`에는 기존 판정·TMX 좌표/GID·원본 PNG/RGBA SHA 레코드·B/C 차이·품질 의견·교차근거를 함께 수록.

## 벽·상위 레이어 가림과 노출 차이

- `location_shop_accessories_01/23` (1895): A에는 작은 회색 사각 물체가 있는데 기존 실제 B−C는 **1픽셀**. 지도에서 완전히 노출된 소형 가구라고 판단 금지.
- `location_shop_fossoil_01/9` (1911): A에는 푸른색·주황색 상부 줄무늬와 가느다란 흰색 세로 지주가 있으나 원본 B−C는 **11픽셀**. 주변 벽·상층·다른 물체의 가림 가능성을 포함해 노출 원인은 미정.
- `Spiffo's` 간판·로고 중에는 A가 구부러진 글자 한 획이나 표지판 모서리인 경우가 있으므로 B의 식당 전체를 단일 타일 정체로 역투사 금지.
- `location_shop_generic_01`의 선반, 카운터는 개별 A가 수평판 한두 개/세로판 한 장뿐인 경우도 있으며, B의 완성 상점·판매 가능 기능을 인증하지 않음.

사용자 미판정10 활성 제외와 v205 대상 155종 교집합 0. 사용자 수동 잠정23 원문·이전 수동80/제외14 보존. 이전 5개 보류 `1845·1917·1970·1992·1994`를 활성화하지 않음. 원본 PNG/TMX·이전 리뷰·SQLite v196(과거 기록 SHA `d006c491…`, 256개 테이블)는 **파일 변경 없이 유지**. 기존 SQLite의 `integrity_check=ok`는 과거 자료의 기록이고 **이번에 물리 파일을 새로 복원하여 PRAGMA를 실행하지는 않았음**.
