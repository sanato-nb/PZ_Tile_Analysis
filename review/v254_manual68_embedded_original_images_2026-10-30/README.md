# v254 — 이미지가 자동 표시되는 오프라인 수동검수기 (68종)

## 수정 이유

v253 검수기에서 사용자가 **이미지 폴더의 파일 410개를 선택했는데도 카드에 이미지가 표시되지 않았다**. 이전 검수기의 미리보기는 폴더 안의 파일 이름이 **v251의 특정 A 접촉시트/B-C 증거 파일명**과 정확히 일치해야 했고, 비공개 GitHub 이미지 링크는 HTML에서 직접 로드되지 않았다.

v254에서는 이 의존성을 없앴다. **68개 타일마다 실제 원본 A PNG, A 원본 알파 영역 확대본(판독용), 실제 TMX B/C 원본 증거 PNG를 모두 단일 HTML 안에 직접 내장**했다. **외부 이미지 폴더 410개, 로그인, 인터넷 없이 열 수 있다.** 사용자 수동 판정 필드와 결과 CSV/JSON 저장 기능은 유지했다.

## 사용법

1. **[PZ_USER_MANUAL_REVIEW_68_IMAGES_INCLUDED.html](PZ_USER_MANUAL_REVIEW_68_IMAGES_INCLUDED.html)** 파일의 GitHub 페이지에서 **Download raw**로 약 **12.6MB** 파일을 다운로드한다. *브라우저의 GitHub 코드 미리보기 대신 실제 HTML 파일을 내려받아* Chrome/Edge에서 연다.
2. 처음 나타나는 **정체 불명 3종** 또는 **재검수 65종** 카드에서 A 원본과 A 확대, **실제 B 및 단일 목표 GID 제거 C/B−C 차이**가 **자동 표시**되는지 확인한다. 이제 로컬 이미지 폴더를 따로 선택하지 않는다.
3. 내 수동 판정, 사물 이름, 타일의 부품 역할, 방향·연결, 재질, 확신도, 근거/메모를 입력한다. 브라우저 저장은 환경에 따라 제한이 있으므로 **JSON 중간 백업**, 최종 **68종 결과 CSV 저장**을 자주 이용한다.
4. 기존 v253에서 입력한 판정이 새 HTML에 자동으로 나타나지 않으면 기존 HTML에서 **JSON 중간 백업** 후 새 HTML의 **기존 JSON 판정 불러오기**로 복원한다. JSON 저장 형식 `PZ_manual68_v253`은 호환 유지했다.
5. 완료한 CSV 파일을 이 채팅에 올리면 사용자 확인 내용에 따라 별도 append-only 사용자 판정 오버레이를 만들 수 있다. **미판정/제외는 자동 확정 또는 DB 활성화하지 않는다.**

## 시각적 근거의 진위

- 정확한 **68개 원본 A lossless PNG SHA256 및 RGBA 픽셀 바이트 SHA256 모두 재검증**.
- 해당 원본 PNG가 들어 있는 v119 ZIP 샤드 **10개 SHA256 확인**.
- v251에서 **실제 단일 TMX 위치로 렌더한 68개 원본 B/C 비교 PNG를 변형하지 않고 무손실 그대로** 내장. 각 B/C PNG의 SHA256은 [EMBEDDED_68_ORIGINAL_A_AND_REAL_BC_SHA.csv](EMBEDDED_68_ORIGINAL_A_AND_REAL_BC_SHA.csv)에 저장.
- 원본 A는 **원래 투명 영역·크롭 좌표를 그대로 포함한 버전**과, 작은 타일의 모습 판독을 위해 **알파 바운딩 박스만 보이도록 확대한 별도 진단 이미지**를 나란히 표시한다. 확대 버전은 원본 A 증거를 대체하지 않는다.
- 기존 v251/v252/v253 자료, 원본 TMX/PNG, 사용자 이전 결정, v240 SQLite 및 활성 9,587/비활성 455 상태를 수정하지 않았다.

## 검증

- GitHub Actions: 68개 원본 A, 68개 실제 B/C PNG, 68개 진단 확대 — **총 204개 이미지가 누락 없이 내장**됐음을 기계 검사.
- HTML JavaScript `node --check` 구문 검사 통과.
- **오프라인 헤드리스 Chrome**에서 HTML을 직접 열어 **A 원본·A 확대·B/C 3개 이미지 실제 표시**를 확인. [브라우저 표시 결과](OFFLINE_FIRST_CARD_BROWSER_PROOF.png).
- 사용자 직접 입력 0종, 모델의 새로운 정체 인증 0종. 이 변경은 **이미지 표시 문제 해결**만 위한 것.

기존 v253 HTML은 역사적 상태로 보존하고, **이 v254 HTML을 최신 수동 검수기**로 사용한다.
