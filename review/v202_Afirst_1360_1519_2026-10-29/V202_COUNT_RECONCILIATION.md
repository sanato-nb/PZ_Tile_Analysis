# v202 변경 건수 해석 통일

기존 v202 기본 A 우선 검수 파일 `A_FIRST_REAUDIT_152.csv`와 `CHANGE_COUNTS.json`, `MANIFEST.json`의 상호 배타적인 분류를 **공식 QA 집계 기준**으로 삼는다:

- `candidate_role_narrowed` **49종** — 원래 기능 또는 부품 역할을 축소 권고. 확정 오류 아님.
- `A_morphology_refined` **69종** — A 개별 외형을 더 구체적으로 설명.
- `historical_candidate_supported` **34종** — 기존 잠정 외형을 유지.
- **합계 152종**, 변경 제안 또는 설명 보완 **118종 = 49+69**, 기존 후보 유지 **34종**. 기존 보류 8종 별도.
- B−C 50픽셀 이하 **6종**은 위 분류와 중복되는 *비배타적 주의 표식*.

추가적인 `CHANGE_AUDIT_AND_PROVENANCE_152.csv` 및 `V202_CHANGE_COUNTS.json`에는 별도의 **엄격한 2차 A-only 경고 규칙**을 적용해 *35종*을 잠정 역할·정체 재판정 대상으로 표시했다. 이 35종은 기본 분류의 49종과 동일한 정의가 아니다. 실제 교집합은 **23종**, 기본 49종만 포함한 항목은 **26종**, 2차 엄격 경고만 포함한 항목은 **12종**, 합집합은 **61종**이다. 따라서 **49+35를 더하거나, 35가 49의 부분집합이라고 계산하면 안 된다.** 2차 파일의 나머지 117종도 기본 분류에서 전부 '설명만 수정'이라는 뜻은 아니다.

보고서/진행률에 쓰는 기본 건수는 **49 역할 축소 권고 / 69 외형 정밀화 / 34 유지 / 8 기존 제외 보존**이다. 2차 35종은 보조 독립 의견으로만 보고, 고유 신규 재검수 152종을 중복 계산하지 않는다.

어느 쪽도 기존 v196 SQLite 상태를 변경하지 않았고, 공식 매핑·TileZed·최종 정체 인증은 **0**이며, 사용자 미판정10 활성 제외를 유지한다. 이번에 TMX B/C를 새로 렌더하거나 동일 키의 다른 공식 A를 대입한 D 실험도 수행하지 않았다.
