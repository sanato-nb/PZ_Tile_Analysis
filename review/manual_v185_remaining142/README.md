## 사용법

1. HTML 파일을 열어 왼쪽의 타일을 선택하고 오른쪽에서 원본 A 및 v182 진단 시트 이미지를 확인.
2. 실제 원본 A의 모양을 확인하면서 `판정 / 확신 정도 / 후보 부분 / 부품 역할 / 재질 / 근거 메모`를 입력하고 저장.
3. 전체 또는 일부를 검수한 뒤 **검수 결과 CSV 저장**을 클릭하고 이 파일을 채팅에 업로드하면, 원본 TMX 및 증거를 다시 대조해 DB 반영 후보를 검증할 수 있음.
4. 브라우저별 데이터는 임시로 저장되므로 정기적으로 CSV 또는 JSON 백업을 내려받기.
