# v194 초기 두 번째 추가 배치 160..319 원본 A 우선 독립 재감사

사용자 지적: 두 번째 추가 배치부터 타일 원본 A가 아니라 주변 B/C 장면만 보고 사물 이름을 붙였을 위험을 감사했습니다. 첫 단계로 160~319 총 160개 정확한 원본 PNG 바이트 SHA256 및 해당 크롭 RGBA 픽셀 SHA256를 독립 검증하고 A만 담은 네 장의 새 접촉시트를 작성했습니다. 이전 후보/부분역할과 원본 A에서 독립으로 보이는 실제 형상을 분리했습니다.

- **25종**은 B의 조립된 주변 사물이나 용도까지 개별 A에 귀속했을 가능성이 보여, 원본 A의 형상 한정으로 후보 구체성을 낮춰 재검토하도록 표시. 대표적으로 180-182 장작더미 조각, 187-192 캠핑 바닥/매트와 침낭 추측, 196/197/201/202 텐트 단일 평판, 305-312 흰 가지형 조각을 장식물로 단정한 사례입니다.
- 나머지 **135종**은 이번에는 A 출처·이미지 무결성만 확인했고, 모든 실물 정체를 독립 재인증했다고 주장하지 않습니다. 기존 A/B/C 관찰 기록과 SQLite/PROJECT_STATE를 변경하지 않았고, 이번 QA에서 추가 관찰/공식 매핑/최종 인증은 0입니다.
- PZwiki:Tile list는 두 목록(Moveables_EN, script-derived)에서 물체의 일반 명칭을 참고할 수 있으나, 모든 원본 타일의 PNG 크롭/Local ID/모든 건축 부품 대응표는 아니어서 공식 맵핑 증거로 사용하지 않았습니다.
- 후속 범위는 idx320 이후 전체 기존 관찰 기록을 버전별로 원본 A 시트에 기반해 재확인하는 것. 현재 상태 v192의 10,007/10,042(99.65%)는 *역사적 잠정 기록률*이며, 이번 원본 A 독립 재감사까지 모두 통과한 비율이 아닙니다.
