# v155 벽면 포스터·사진·작은 표식과 차양 조각 A/B/C 개별 시각 검수 3280~3439

원본 A 접촉시트 041/042, 원본 TMX B(5x5) 주변 장면 041/042, 한 GID만 제거한 C 및 B−C 차이 접촉시트를 실제 관찰하여 총 160종의 형태·색상·부분 역할·재질·신뢰도를 잠정 기록했다. 3280~3284는 주황 줄무늬 차양 부품, 나머지 대부분은 실내 장식용 소형 벽그림·사진·인쇄 포스터·표지판 조각이다. 너무 작은 사진 안의 인물과 글자 내용은 미확정이다.
