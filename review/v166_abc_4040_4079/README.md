# v166 4040~4079 벽돌무늬·수평 사이딩 박공 외벽 40종 A/B/C 시각 검토

원본 A050, 실제 TMX 5×5 B050, 동일 원시 GID/층/레이어/좌표에서 대상 타일만 제거한 C050 및 B−C 차이 접촉시트를 직접 열어 40종을 관찰했다. 30_07 원본 전체 PNG에서는 황갈색·밝은 베이지색 벽돌 줄눈, 30_08에서는 적갈색 벽돌 줄눈, 30_09에서는 분홍회색 수평 사이딩을 확인했다. A/B/C CSV의 행 인덱스는 2163번의 A 보류로 어긋나므로 반드시 (tile_set_name,local_id)로 결합한다. 4040~4062는 황갈색/밝은 베이지 벽돌무늬, 4063~4070은 적갈색 벽돌무늬, 4071~4079는 분홍회색 사이딩 박공벽 단편이다. B−C=0 또는 변화가 12픽셀 이하인 4040,4041,4042,4043,4044,4047,4048,4049,4050,4059,4070,4075,4076은 판독 근거 부족으로 수동 보류한다. 자동 원본 검증에서 지도끝·이웃누락·기존 관찰 중복에 따라 추가 보류 가능.

원본 PNG 파일 SHA256와 RGBA 크롭 픽셀 SHA256, TMX raw GID/층/레이어/좌표, B/C/DELTA ZIP SHA256/CRC, 부모 v165의 227개 SQLite 테이블과 모든 행 수 보존, 중복키 및 PRAGMA integrity_check를 통과한 경우에만 신규 잠정 관찰로 기록한다. 원본 84 TMX·Tiles PNG, 기존 5,409종, 수동80·제외14·D held2·JUMBO20과 과거 모든 DB를 수정하지 않는다. 공식 Local ID/TileZed 매핑, 실제 재질, 연결·방향, 최종 정체 인증은 미확정. D는 동일 키의 다른 공식 A를 원래 B 위치·층·레이어에 교체하는 검증만 인정하며 이 회차에서는 수행하지 않았다.
