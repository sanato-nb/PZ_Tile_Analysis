# v181 실제 추가 TMX 위치의 A/B/C 56종 직접 시각검수 37종 신규 잠정 정체

v180에서 원본 TMX의 새 배치로 다시 조립한 총 56종/접촉시트10장을 직접 시각 판독. B−C 변화 양수47 중, A 단독 외형 및 B 문맥이 일치하고 변화100픽셀 이상이며 이웃 PNG 누락이 없는 37종만 신규 provisional_candidate 등록. 변화 0인9/100픽셀 미만9/주변 PNG 한 건 누락1 등 19종은 계속 보류.
