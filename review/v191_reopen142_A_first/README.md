# v191 명시적으로 다시 열린 142종 — 원본 이미지 A 우선 판독용 실제 시트

사용자가 제외됐던 142종을 다시 검수하라고 지시하여, 원래 v188 제외 기록을 보존한 상태로 신규 133개와 오래된 9개 키를 모두 검수 대상으로 재개합니다.
원본 PNG 바이트 SHA256와 A RGBA 픽셀 SHA256 검사를 통과한 원본 스프라이트를 왼쪽에 전체 표시하고, 오른쪽에는 **같은 A 픽셀의 비투명 영역만 확대** 표시합니다. 오른쪽 확대는 새로운 이미지나 다른 타일이 아닙니다. 사물 정체와 연결을 알려면 반드시 이 이미지 시트를 사람이 직접 시각적으로 보고 B/C/배치 근거와 나중에 함께 검수해야 합니다.
오래된 원본9개는 공식 원본 A의 정확한 크롭/LocalID 대응이 아직 검증되지 않았으므로 아무 임의 이미지도 대신 사용하지 않습니다.
이번 단계는 근거 시트 제작과 원본 이미지 무결성 감사이며, 시트가 생성되었다는 사실만으로 관찰 완료하거나 100%로 표시하지 않습니다. 원본 DB, 사용자 과거 제외 지시, D/JUMBO 보류, 공식 매핑/TileZed/최종 인증은 변경하지 않습니다.
