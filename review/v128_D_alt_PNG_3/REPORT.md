# v128 D: 3개 다른 원본 PNG 후보로 같은 B 위치 재조립

D는 원래 B 위치·레이어·raw GID를 고정하고, 동일 타일명/Local ID의 다른 동명 PNG 후보 크롭을 같은 좌표에 하나만 교체해서 재렌더링한 장면이다. v124 두 번째 사용 위치나 옆 타일(Local ID 추정)을 이용하지 않았다.
- 검증된 파일 변형 후보: 3종. 재조립한 D: 3종.
- B와 D 장면 픽셀 변화 있음 3종, 변화 없음 0종.
- 원본 A, 다른 PNG의 A, B, C, D 및 B-D 차이 이미지를 PNG로 보존. 원본 소스 PNG/TMX의 SHA와 선택 크롭 RGBA 해시 확인.
- 후속: 이미지 육안 판단 및 TileZed/공식 매핑 근거 수집. 문맥에서 변경된다는 사실만으로 후보를 정답으로 확정하면 안 됨.
- 기존 5,409종·수동80·제외14·구 SQLite 189테이블 보존. 최종 인증 및 직접 이미지 정체 판독 새 증가 0.
