# v178 대형 배치: 163개 원본 A 대응 타일의 다른 실제 TMX A/B/C 재조립

v175 전체 대체장면 후보 220종 중 기존 5409키에 속한 9종은 새 A 원본 크롭 선택 기록이 없으므로 이 스크립트로 허위 A를 그리지 않는다. 새 A 원본 근거가 있는 211종 중 v176가 렌더링한 48종을 정확한 정렬 기준과 (tile_set_name,local_id)로 제외한 **163종 전부**를 단일 배치로 재조립한다. 원본 A PNG를 그대로 쓰고 실제 다른 TMX 레이어·층·raw GID 위치에 배치한 B, 해당 GID 하나만 뺀 C, 색 차이 이미지를 원본 PNG ZIP과 6종씩 접촉시트로 저장한다.

원본 A RGBA 픽셀 SHA, PNG 해시, 실제 TMX GID/좌표/레이어/층, C 단일 제거, B/C 4장/종 ZIP CRC와 부모 v177 SQLite 239개 기존 테이블의 모든 행 내용/수 보존 확인. 신규 SQLite 증거 163행을 v178 240번째 테이블에만 추가. 생성만으로 이미지 관찰이나 최종 인증으로 간주하지 않는다. 누적 관찰 9684/10042(96.43%), 기록상 미관찰 358, 실제 미관찰 키 356+집계 차이2 유지. 다음 검수에서 실제 새 장면을 눈으로 판독한 후에만 신규 provisional 후보 인정. 기존 5409중 원본 A 대응이 없는 9종은 별도 근거 발굴 대상. 사용자 정의 D(다른 공식 A를 같은 B 위치에 교체) 아님.
