## 해결되지 않은 문제와 데이터 오용 방지

1. **B−C 변화 양수는 그 원본 TMX 위치에서 목표 타일이 화면에 기여했음을 보여줄 뿐 공식 사물 이름·완성 부품 기능의 인증은 아니다.** 누락 없이 큰 물체를 볼 수 있어도 연결 짝/방향/TileZed 속성은 별도.
2. 38종 중 30종은 목표 레이어까지만 렌더하면 나타나므로 **이후 레이어가 가리는 사실은 지지**되지만, 특정 어떤 벽·지붕/이웃 셀이 원인인지 정확한 원인 분리 마스킹을 하지 않았다. 나머지 8종의 0은 **아예 투명/빈 타일이라는 뜻이 아니다**.
3. **13종에 경고:** `walls_exterior_house_05/114`, `walls_interior_house_07/*`, `walls_interior_house_11/*` 일부 A 크롭에 **큰 빨강 단색 영역**이 같이 표시된다. 원본 A RGBA/크롭 경계·게임 실제 표시 용도를 추가 확인하기 전 이 빨강을 Minecraft 벽 색/블록으로 사용하는 것은 위험. 이 13키는 CSV에서 `source_red_opaque_warning`으로 표기.
4. 251종 중 **107종 새 구체 형태 주석 + 14종 이전 구체 판독**을 저장했다. **130종은 계열 수준의 잠정 유형**과 기존 A 직접 형태 기술을 보존한 것이며 개별 정체 완전 확정이나 다른 모든 C 이미지의 수동 판독을 뜻하지 않는다.
5. 이미지 렌더는 원래 TMX CSV/좌표/GID/레이어와 원본 atlas PNG 크롭 바이트를 사용한 이소메트릭 유사 재조립이다. **실제 게임 클라이언트/TileZed 공식 렌더와 완전히 동일하다는 인증은 아니다**.
6. 사용자 이전 수동 판정, 원본 PNG·84 TMX, 모든 기존 SQLite 및 v240 전체 10,042 / 활성 9,587 / 비활성 455 기록은 보존했다. 제외 188종은 이 v248 검수 CSV에 넣지 않았지만 원본 기록을 삭제한 것은 아니다. 사용자 미판정10·기타 제외6도 활성화하지 않았다.

후속 작업은 **38종에 대한 정확한 가림 셀 마스킹**, **붉은 단색 원본 A 13종의 픽셀 의미 확인**, **130종 계열분류의 개별 부품 연결·공식 명칭 교차 검증**이 핵심이다.
