## 결론

**v238의 역사적 보류 439종은 이미 v232~v237에서 원본 A의 외형과 과거 원본 TMX B/C 증거를 다시 판독한 439개의 서로 다른 소스 키이다.** 즉 **439개 모두를 전혀 검수하지 않았다고 말하면 틀리다**. 다만 해당 439개는 **개별 정체·공식 Local ID 인증**을 마친 타일도 아니다.

이번 v239에서는 439행을 GitHub 최신 v238 보류 원장·7개 소스 마스터 분할 파일·OPEN_ISSUES_448의 상태에 대해 **439/439 키 대조, 고유키 중복 0, 기존 TMX 및 raw GID·B−C 수치 충돌 0**으로 다시 확인했다. 새로운 439건의 완전한 원본 PNG 픽셀 디코드, B/C 레이어별 렌더링, 벽을 제거한 독립적인 가림 실험은 수행하지 않았다. 전수 교차검증은 **기록 정합성** 검증이며 **정체 확정**과 다르다.

분류는 **B−C=0 가림 원인 미검증 209 / 지도 끝 잘림 45 / 주변 PNG 부재 8 / 독립 기능·부품 정체 또는 배치 미확정 177 = 439**이다. 서로 다른 소스 키 수와 이 4개 배타적 이슈 구분이 정확히 일치한다.

A 원본 접촉시트 `SELECTED_A_000.jpg`, `SELECTED_A_005.jpg`, 실제 TMX B/하나의 GID를 제거한 C 비교 시트 `C_B_DIFF_000.jpg`, `C_B_DIFF_005.jpg`와 v185 실물 대체 배치 이미지 `3102_ALT_TRUE_ABC.jpg`를 재열람했다. 각 기존 v232~v237 보류의 이전 개별 A 노트는 **이번에 새로 439개 작성한 것이 아니라 원래 기록을 보존해 연결**했다.
