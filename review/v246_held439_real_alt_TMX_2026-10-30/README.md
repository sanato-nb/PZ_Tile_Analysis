# v246 — 보류 439종 동일 키 다른 실제 TMX 위치 전수 탐색

사용자 지시: `타일의 사물이 무엇인지 알아내고, 불명확하면 동일 타일의 다른 위치를 보라.`

**원본 TMX 84개 전부를 파일 크기와 SHA-256으로 새 검증**해 각 층/레이어의 원래 raw GID를 `(tile_set_name,local_id)`로 역변환하여 역사적 보류439종 **실제 출현 위치 2,256건**을 재탐색했다. A 이미지·정체를 추측하여 위치를 만들어낸 것이 아니라 원본 레이어의 실제 비영(非零) GID 셀에서만 취합했다.

| 항목 | 수량 |
|---|---:|
| 원본 TMX 새 SHA 검증 | **84/84** |
| 역사적 보류 대상 고유키 | **439** |
| TMX 안에 실제로 찾은 원본 타일 배치 | **2,256** |
| 원래 대표장면 외의 다른 실제 배치가 있는 키 | **251** |
| 다른 실제 배치가 없었던 키 | **188** |
| 지도 5×5 경계에 안 걸리는 다른 배치가 있는 키 | **244** |

[439종 개별 다른 배치 조사](HELD439_ALTERNATE_SITE_CENSUS.csv) · [모든 실제 원본 출현 좌표](ALL_HELD_REAL_TMX_OCCURRENCES.csv) · [각 키의 우선 대체 위치 5개](BEST_FIVE_REAL_ALTERNATE_SITES.csv) · [검수 범위](MANIFEST.json).

각 행에 원본 TMX 파일과 SHA, 층, 레이어, x/y, raw GID, 5×5 지도 끝 거리, 같은 셀의 위쪽 레이어 존재 수가 담겼다. **같은 셀 위쪽 레이어 0은 주변 셀의 높은 벽/지붕까지 가리지 않는다는 증거가 아니다.** 이 목록은 위치 탐색 증거이며 각 키의 정체 최종 인증이 아니다.

v247에서는 이 조사에서 선정한 **14키·27개의 다른 실제 배치**를 진짜 A/B/C로 다시 렌더링해 눈으로 비교한다. [v247 이미지/사물 후보](../v247_held439_alternate_true_BC_selected_2026-10-30/).
