# v154 3120~3279 농작물·정원·상업 벽·차양막 개별 A/B/C 이미지 검수

A039/A040 원본 타일을 직접 보고 해당 타일이 놓인 실제 TMX 주변 B039/B040와 동일 위치·층·레이어에서 하나만 제거한 C/B-C 차이를 시각 대조하였다. 총 160개 인덱스에 대해 재배 작물, 말라가는 작물, 실내 화분, 전정 관목, 벽의 검은 연소 흔적, 상업 벽판/코너/문설주, 간판/벽걸이 장식 및 청백·적백 스트라이프 차양의 외형·부품 역할·재질·신뢰도를 잠정 기록했다. 매우 작은 조각의 정확한 방향·연결·재질과 공식 A 매핑은 미검증.
