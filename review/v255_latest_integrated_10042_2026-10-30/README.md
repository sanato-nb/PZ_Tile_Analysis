## 우선순위·검수 범위

1. 정확한 `(tile_set_name,local_id)` = `source_key`로만 조인, 중복 검증. v248 **251종**(다른 실제 TMX 사용 위치)와 v251 **188종**(단일 위치)은 서로 다르며 합계 **439종**.
2. 251종은 v248 A 기반 가설 → v249의 가림 38종 개별 A 묘사 → v250의 추가 112종 개별 A 묘사가 있을 때 높은 버전을 사용. **서로 다른 키 수 251**을 유지하며 중복 추가하지 않는다.
3. 188종은 v251 원본 A 형태·실제 B/C를 기본으로 하고 v252의 수동 재판독 65종을 **잠정 설명**으로 우선한다.
4. v254 **사용자 68종**이 있으면 최우선. **명시 사물 이름 4종 + 부품 판독 12종**에는 사용자 입력 원문을 우선하고, **미선택52종은 기존 v252 후보(없으면 v251)에 동의**한 것으로 유지. 미선택 중 2종의 보충 의견은 별도 컬럼에 보존. 사용자 문구 자체는 절대로 교정하거나 축약해 원본 CSV에 덮어쓰지 않는다.
5. 439종은 **여전히 v240 원장상 보류/비활성**이다. 시각적 정체 후보를 알아냈다고 실제 맵 구조·최종 마크 블록으로 자동 승격하지 않는다. 나머지 9,603종의 새 메타데이터 칼럼은 비워둔다.
