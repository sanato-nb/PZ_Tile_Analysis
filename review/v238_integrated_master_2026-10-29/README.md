## 3. 437 vs 439 보류 집계의 처리

- 과거 v231의 **보류 437종**은 원래 발표된 **집계 수치**로 보존하며 이를 새 원본 데이터에 덮어쓰지 않았다.
- v232(30행) + v233(100) + v234(100) + v235(111) + v236(72) + v237(26) = **439행**을 **원본 신규 4,633키의 실제 소스 인덱스와 직접 조인**한 결과, **인덱스 중복0·키 중복0·타일 키 충돌0**이었다.
- 따라서 보류 439건을 **중복 2행 삭제**해서 437로 맞추는 것은 근거 없는 조치다. 새 통합 원장은 재현 가능한 **439개 소스키**를 보류로 유지한다.
- 반면 과거 발표값437에서 정확히 **어떤 두 행이 빠져 계산되었는지는 아직 별도 역사적 집계 출처로 특정하지 못했으며**, 종전 `4196+437=4633` 숫자를 이제 증거 없는 확정 분류 수치로 반복하지 않는다.
- 이번 통합 4,185 + 439 + 8 + 1 = **4,633**으로 **서로 겹치지 않는 실제 소스키 기준 집계**를 확보했다. 이 숫자 변화는 신규 타일 관찰/보류 해제 결과가 아니라 **원장 집계 정합성의 교정**이다.
