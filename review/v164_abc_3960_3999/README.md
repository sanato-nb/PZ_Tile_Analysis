# v164 3960~3999 박공벽·외장판 40종 A/B/C 시각 검토

원본 A049, 실제 TMX 원배치 B049, 한 raw GID만 제거한 C049, B−C 접촉시트를 눈으로 대조하여 40종의 외형·부품 역할·재질 후보를 기록. 3960~3971 적갈색 벽돌무늬 경사 박공판, 3972~3979 갈색 수평 외장판과 미세 쐐기, 3980~3999 회갈색·베이지색 수평 사이딩 및 지붕선 아래 연결 조각. 아주 작은 조각과 B−C 변화가 희미한 타일은 보류. 정확한 방향·연결, 공식 Local ID/TileZed 매핑과 최종 정체는 인증하지 않음.

독립 원본 PNG SHA256·RGBA 픽셀 SHA256·TMX raw GID·층·레이어·좌표, B/C/DELTA ZIP SHA256·CRC, 부모 v163의 225개 SQLite 테이블 모든 행 보존, 중복키와 PRAGMA integrity_check 검증을 통과한 경우에만 27종 잠정 관찰과 13종 보류를 반영. 원본 84 TMX, Tiles PNG, 기존 5,409, 수동 80, 제외 14, held D2/JUMBO20 및 이전 DB는 변경하지 않음.

D는 같은 키의 공식 다른 A를 원래 B 동일 위치·층·레이어에 넣는 실험만 유효하며, 인접 격자와 다른 TMX 위치를 공식 인증으로 사용하지 않음.
