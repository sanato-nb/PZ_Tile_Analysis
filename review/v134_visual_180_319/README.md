# v134 실제 신규 타일 A/B/C 이미지 정체 판독

기존 시각 접촉시트 180~319에서 타일별 외형·역할·재질을 수동 관찰하였고, 각 결과의 원본 PNG RGBA 픽셀 해시, 실제 TMX GID·층·레이어·위치, B/C/픽셀차이 파일을 다시 검증하였다. B−C 변화 0, B 이웃 결손, 지도 경계 대상은 별도 CSV에 보류하고 신규 관찰 수치에 포함하지 않았다. 기존 D 인접격자/두 번째 배치는 현재 사용자 정의의 공식 다른 A 인증이 아니므로 정체 인증에 사용하지 않는다.

모든 식별은 provisional_candidate, 정확한 타일셋 아틀라스 이미지/TileZed/최종 정체 인증 0. 증거 ZIP은 정확한 원본 A·B·C·픽셀차이 네 종류씩 수록한다. 부모 v133 195 물리 테이블과 이전 행 수는 전부 보존하고 v134 한 테이블만 덧붙여 196테이블이다. 사용자 제외/수동기록/보류와 모든 PNG/TMX 원본을 변경하지 않았다.
