# 남은 실제 타일 33종 수동 검수 패키지

1. \`수동검수_33종_오프라인_패키지.zip\`을 다운로드해 압축을 푸세요.
2. \`PZ_남은33종_수동검수.html\`을 Chrome/Edge로 열면 인터넷 없이 원본 A 23개와 실제 TMX B·C 장면을 함께 검수할 수 있습니다.
3. 나머지 10개는 정확한 원본 A가 검증되지 않았기 때문에 임의 이미지를 넣지 않았고, 원본을 직접 첨부할 수 있는 칸을 제공합니다.
4. 사용자 판정(잠정 후보/보류/자료필요), 이름, 역할, 재질, 방향, 근거를 입력한 뒤 **JSON 저장**으로 결과를 보관하여 채팅에 업로드하세요. 선택으로 CSV 저장 가능.
5. 판정 데이터는 이 컴퓨터의 브라우저 로컬 저장소에 임시 보관됩니다. 다른 기기에서 이어할 때는 JSON 불러오기를 사용하세요.
6. HTML에 직접 포함된 B/C는 실제 원본 TMX 장면의 축소 미리보기입니다. 레이어 마스킹 진단 X/Y와 다릅니다. B−C=0이라도 원본 A 판독은 유효한 보조 근거입니다.
7. 33종 검수 양식은 사용자 참여용이며, 원본 SQLite·PROJECT_STATE·기존 제외 이력·최종 인증/공식 매핑을 바꾸지 않습니다. 과거 2개 집계불일치는 특정 타일 ID가 아니므로 사용자 검수 33종에 섞지 않았습니다.
