# v174 원본 박공·사이딩 계열의 과거 시각근거 부족 보류 58종 집중 재검수

기존 v158·v160~v168에서 오직 manual_visual_insufficient 사유로 보류했던 58개 (tile_set_name,local_id)를 원본 A046~051, TMX B046~051, C 단일제거/차이 046~051에 대응하여 다시 비교했다. 원본의 작은 조각 중 벽돌/석재무늬 및 세로 사이딩 박공 경계 형태가 큰 동일계열 벽판에 이어진다고 관찰 가능한 49종은 신뢰도 low·부분계열 잠정 후보로만 기록했다. 나머지 9종은 지속 보류. 현재 추론은 최종 물건 정체/물성/벽 방향·조립 연결·TileZed 정식 매핑을 확정하지 않는다.

신규 승격은 원본 PNG 파일 SHA256, A 크롭 RGBA 픽셀 SHA256, 원본 TMX의 실제 raw GID·층/레이어/x/y, B/C/DELTA ZIP SHA256·CRC, 동일 장소 차이 픽셀 >0, 부모 키 중복 금지, 지도끝·이웃 부족 미해당 조건을 모두 검사해야 한다. B−C=0/맵끝/이웃 근거 없음/기존 관찰 중복인 타일들은 이번 재검수 대상에서 제외한다. 신규 관찰이라도 confidence=low이며 기존 보류 근거와 대조를 기록.
