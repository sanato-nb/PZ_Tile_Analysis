# v162 3880~3919 연베이지·녹회색 경사지붕 박공 측벽 조각 40종 A/B/C 실제 시각 관찰

원본 A048, 원래 TMX B048 및 동일 층·레이어·위치에서 단일 GID만 제거한 C048와 B−C 픽셀 차이 이미지 40종을 직접 확인했다. 3880~3888은 회베이지색 박공 측벽 쐐기·사선 판, 3889~3899는 적갈색 벽돌무늬 경사 외벽, 3900~3919는 주황갈색·적갈색 벽돌무늬의 높이별 박공 외벽 조각이다. 타일별 외형·부분 역할·재질 추정·신뢰도를 JSON으로 보존한다. 실제 방향·연결 및 공식 Local ID/TileZed/최종 정체는 미검증이다.

신규 잠정 관찰 등록 전 원본 PNG 바이트 및 RGBA 크롭 픽셀 SHA256, 실제 TMX 원시 GID·좌표·층·레이어, B/C/DELTA 원본 ZIP SHA/CRC, 중복키 및 부모 v161의 223개 물리 SQLite 테이블·모든 기존 행 보존을 검증한다. B−C=0, 지도끝, 주변 누락, 기존 관찰 중복 및 육안 판독 부족은 예외표로 분리하고 투명 또는 최종 정체로 인증하지 않는다. A/B/C 접촉시트 이미지 자체를 TileZed 공식 매핑으로 취급하지 않는다. D는 동일 키의 공식 다른 A를 원래 B 동일 위치·층·레이어에서 교체하는 검증으로 아직 인증되지 않았다.
