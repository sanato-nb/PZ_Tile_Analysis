## 사용 방법

1. [HTML](current/v243_floorplan_v240_priority.html)을 다운로드해 Chrome/Edge로 엽니다.
2. 상단에 `v240 우선 10,042 / 활성 9,587`이 표시되는지 확인합니다. 외부 서버 통신 없이 내장된 gzip 사전을 읽습니다.
3. 원본 `.tmx` 파일을 선택합니다. 기존 엔진의 층 전환/확대/벽·가구 표시 기능을 그대로 사용합니다.
4. 도면의 타일을 클릭하면 **v240 원본 A 외형 메모/잠정 후보/사용자 후보/출처/제외 사유**가 이전 v22 정의와 함께 표시됩니다.
5. 형태와 방향이 불확실한 타일은 확정 블록으로 변환하지 말고 A/B/C 실제 증거를 재확인합니다.
