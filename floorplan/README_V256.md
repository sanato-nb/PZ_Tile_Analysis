# v256 — 최신 통합 10,042종 실행형 TMX 평면도

최신 데이터 기준은 **v255 전체 마스터**이며, **v256은 평면도 시스템 실행본의 버전**이다. v255 원본 데이터베이스나 검수 결과를 새로 인증한 것이 아니다.

## 실행 파일

**[v256 최신 통합 평면도 HTML](current/v256_floorplan_unified_10042.html)** — 단독 HTML을 내려받아 Chrome/Edge로 열고 `.tmx` 파일(필요한 경우 `.tsx`도 함께)을 선택한다. 외부 서버 업로드가 필요하지 않다.

최신 통합 CSV `review/v255_latest_integrated_10042_2026-10-30/MASTER_ALL_10042_LATEST_PREFERRED.csv`의 SHA256을 재확인하고 정확한 10,042개의 `source_key`를 **전부 HTML에 압축 내장**한다. 사용자 직접 선택16종이 기존 AI 잠정 이름보다 우선, 미선택52종은 기존 잠정 후보 동의로 유지된다. 보류439종에는 v248–v254의 최신 A 형태·부품 후보·원래 B/C 증거를 붙인다.

## UI

- **TMX + TSX** 불러오기: 원본 GID/firstgid를 매핑하고 레이어·층·방을 읽는다. 원본 TMX 84개를 합쳐서 지리적으로 붙이는 기능은 없음 — 파일별 평면도다.
- **층 선택, 층 내 레이어 온/오프, 확대/이동, 벽·문·창·바닥·가구·기둥/지붕** 표시: 원래 v22.1/v243 기능 유지.
- **전체 10,042종의 정체 이름/고유키 검색**: 예 `constructedobjects_01/18`, `쥐덫`. 항목을 클릭하면 **현재 연 TMX에 실제 배치된 첫 위치로 이동**하고 원본 GID/타일셋 및 모든 레이어를 검사한다. 해당 타일이 그 TMX에 없을 때는 별도 안내한다.
- **좌표 검사**: v255 전체 최신 잠정 이름, A 원본 형태 메모, 최신 분석 출처, v254 사용자 원문 사물명·부품·방향·메모, 원래 TMX B/C 증거 경로를 원래 레이어와 함께 표시.
- **보류/제외 455종 점선 미리보기**: 타일이 배치된 위치에 분홍 점선을 선택적으로 표시하며, 이 상태의 타일을 **벽선·문·바닥·가구로 자동 분류하지 않는다**. 439종 보류 및 역사적 사용자 제외16종은 원본에서 삭제하지 않으며, 시각 후보만 표시한다. 맵에서 숨기더라도 검사 창에서 이름 확인 가능.
- 기존 **현재 층 PNG 및 전체 층 ZIP 다운로드**에 더해 **현재 층 CSV 배치 내보내기** 추가. CSV에는 좌표·층·레이어·raw clean GID·고유키·활성 상태·사물명·A 설명·사용자 선택/근거가 남는다. CSV 공식 등 위험 문자를 보수적으로 이스케이프한다.
- 데이터 상태: 10,042종 전체, **활성 9,587**, **보류 439**, **기존 제외 16**, **사용자 직접 판정16+미선택동의52**, 공식 정체 인증 **0**.

## 판독·표현 경계

- 최신 명칭은 게임 공식 Local ID/TileZed 인증이 아닌 **원본 이미지 A 기반 잠정 후보**. B/C=0이라도 가림 레이어 탓일 수 있다. 시각 이름은 물리 구조/방향의 근거가 아니므로 모호한 스프라이트에서 임의로 구조 벽을 만들지 않는다.
- 기존 원본의 벽은 **선형 경계**로 표시한다. Minecraft의 **1블록 두께 벽으로 변환하는 알고리즘**이나 월드 파일 내보내기를 이번 2D 도면에 혼합하지 않았다.
- 기존 v22.1/v243/v255 원본 HTML 및 모든 타일셋 PNG/84 TMX/SQLite/이전 CSV/사용자 수동판정은 그대로 보존했다.
