# v259 · v258 기반 2D 평면도

[단독 HTML](../current/v259_floorplan.html)을 다운로드해 Chrome 또는 Edge에서 연다. **실제 맵 31_46 열기**를 누르면 내장한 원본 TMX가 열린다. 다른 TMX는 파일 선택으로 열고 외부 TSX가 있으면 함께 선택한다.

가구 이름·후보 ID·타일 번호 또는 분류로 검색한다. 후보를 선택하면 해당 부품이 있는 칸들이 주황색으로 강조된다. 이전·다음 위치로 층과 좌표를 이동한다. 배치 수는 원본 레이어의 부품 출현 횟수다. 2칸짜리 가구 하나가 두 번 집계될 수 있다.

타일 10,042종의 원본 속성, 가구 후보 2,197개, 부품별 저장소 근거 1,855건을 내장했다. 좌표를 클릭하면 겹쳐 있는 모든 레이어, 원본 방향·다칸 위치·재질·수납 속성과 후보별 근거가 표시된다. 같은 타일에 연결된 여러 후보를 모두 표시한다. 가구 원장에만 있는 타일도 실제 TMX에서 동일 ID를 찾으면 표시한다. 이미지 보류 34개는 검색 대상에서 제외했다.

가구 분류가 일치하는 활성 타일은 청록색 기호로 표시한다. 가구·장비·계단 표시를 끄면 기본 가구 기호도 꺼진다. 선택 강조는 위치 검수에 쓰며 비활성 타일의 구조 판정과는 별개다. CSV에는 각 배치의 v258 원본 속성과 가구·저장소 근거가 들어간다. 원본의 층·레이어를 선택해 PNG 및 전체 층 ZIP으로도 저장할 수 있다.

재생성하려면 저장소 루트에서 아래 명령을 실행한다.

```sh
python scripts/restore_v258_master.py PZ_B42_v258.sqlite
python floorplan/v259/build.py PZ_B42_v258.sqlite
```
