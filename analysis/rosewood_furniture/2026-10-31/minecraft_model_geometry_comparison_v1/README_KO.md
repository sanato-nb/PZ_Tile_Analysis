# 로즈우드 원본 완성 가구와 실제 Minecraft 1.20.1 Forge 모델 비교

실제 배포된 모드의 blockstates JSON을 열고 연결된 블록 모델의 큐보이드 기하를 복원한 무텍스처 형상도와 좀보이드 완성 가구 PNG/PZ3D를 비교하는 증거 자료다.

- 18개 샘플, 모델 요소 기하 복원 성공 8개
- 실제 Minecraft 게임 내 렌더링(블록 방향/이웃 연결/동작)은 미검증.
- PZ 쪽 다칸 가구 부품은 앞서 완성형 이미지로 조립된 것을 비교한다.
- JAR/OBJ/원본 텍스처는 재배포하지 않고 사용자 연구용 무텍스처 도식만 제공.
- 실제 가구 외형 1:1 확정값이 아니라 수동 시각 검수를 위한 근거다.
