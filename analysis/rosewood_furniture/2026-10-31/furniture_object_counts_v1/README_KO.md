# 로즈우드 실제 가구 단위 수량 감사 — v1

**이 문서는 기존 94,073건의 스프라이트 배치 기록을 가구/설비 물체 단위로 다시 합산한 결과**다. 원본 TMX 56개(중심 24개+외곽/교도소 포함 완충 32개)와 원본 .tiles 속성, SpriteGridPos, 실제 층·좌표를 사용한다.

## 로즈우드 중심 시가지 집계 (TMX X30–33, Y43–48)

- **기본 가구·가전·욕실·싱크·카운터·선반·쓰레기통 등: 15,957개 잠정 물체**
- 그중 **다중 타일 완전 격자 조립 패턴: 2,594개**, 사용된 타일을 단일 물체로 본 **잠정 단일 스프라이트: 13,363개**.
- 중심가에 놓인 **상점 진열대·사무실 책상 등 특수 타일셋에서 이름으로 확인되는 추가 비품: 1,311개 잠정 물체** (다중 조립 278 / 단일 1,033).
- **기본+원본 이름이 명시된 특수 비품까지 확장: 17,268개 잠정 물체**. 더 넓은 범위지만 전체 가구 최종 인증 수는 아님.
- 원본 정보만으로 세지 않은 구조물·특수시설·인테리어 장식·조명은 별도 불확실 항목으로 보존한다.

## 불확실성과 검수 기준

1. **15,957개는 정확한 완성 가구 확정값이 아니다.** 단일 타일 13,363개는 원본에 `SpriteGridPos` 정보가 없어 1타일=1물체로 **잠정 계산한 값**이다. 실제로 여러 조각을 하나로 해야 하면 이 숫자는 줄어든다.
2. 다중 타일 그룹은 원본 `CustomName+GroupName+Facing+SpriteGridPos`, 동일 층·인접 좌표로 묶었다. 8개의 가능한 좌표 변환 중 가장 완전한 패턴을 찾았고, 같은 완전성이 나오는 변환도 있어 자동 100% 인증은 아니다.
3. 불완전하거나 출처가 중복되는 다중 타일은 **무리하게 완성품으로 합산하지 않았다**. 전체 94,073개 원본 GID 중 **62,789개는 별도 미분류·미확정 부품**으로 유지되며, 대부분 비가구·시설·장식 후보도 포함된다. 특히 기본 가구 계열의 미해결 부품은 **75개**다.
4. `location_*` 등 특수 타일셋은 바닥/벽/진열대 등이 혼재하므로 `CustomName`이 명시된 가구 이름만 우선 포함했다. 이름 없는 사무실·상점 가구는 아직 빠질 수 있다.
5. 기준 지역은 **로즈우드 중심을 포함하는 사각 TMX 24개 셀**이다. 공식 도심 경계를 정확히 자른 결과가 아니다. 완충 32셀에는 교도소 및 외곽 지역도 포함한다.
6. 완전 가구를 구성하는 위치와 후보 분류는 추가 시각 검증이 필요하며, 인접 가구끼리 잘못 결합했을 가능성도 배제하지 않는다.

## 결과 파일

- `OBJECT_INSTANCES.csv`: 가구 단위 1행, 실제 세계 좌표·층·원본 이름·원본 Local ID 부품 세트·조립 방식 기록.
- `CORE_FURNITURE_BY_NAME.csv`: 원본 이름별 지역·범위·완전/잠정 수량.
- `CORE_FURNITURE_BY_MODEL.csv`: 이름+GroupName 스타일별 개수.
- `CORE_FURNITURE_BY_CATEGORY.csv`: 카테고리별 개수.
- `GRID_TEMPLATE_ASSEMBLY_RESULTS.csv`: 방향별 조립 템플릿과 완전 패턴 개수.
- `UNRESOLVED_SPRITE_PARTS.csv`: 보류/미분류 62,789개 스프라이트 원본 좌표.
- `ROSEWOOD_FURNITURE_OBJECTS.sqlite`: 객체 단위 조회 SQLite.
- `ROSEWOOD_OBJECT_COUNTS_COMPLETE.zip`: 기본 조립 원장 및 증거 압축본.

기존 원본 PNG, TMX, TBX, 타일 정의, 과거 DB 및 사용자가 내린 판정은 변경하지 않았다.
