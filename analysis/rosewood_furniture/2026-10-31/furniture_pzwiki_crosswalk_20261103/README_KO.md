## 실제 발견한 구조적 혼동

- **PZW-0481 Mirror And Drawers:** 위키 이미지에 두 스프라이트 번호가 연결되지만, 원본에서는 두 종류의 명명 스타일로 분류됨. 자동 병합 금지.
- **PZW-0174 Rocking Chair:** 위키 이미지가 두 로컬 ID를 함께 참조하는데 로즈우드 사용 목록에서는 일부만 나타남. 불완전 다중 타일/방향 이미지 확인 필요.
- **PZW-1164 Sheep Skull on Pole:** 마찬가지로 일부 원본 타일 ID만 로즈우드에서 확인됨.

## 제작용 가구 ID 관리 원칙

기존 Source TileDef의 CustomName + GroupName + 출처 타일셋 + Facing + SpriteGridPos와 Viewpoint 3D 모드의 근거가 가구 정체 판정의 중심이야. 위키 자료는 분류, 이름, 크기(타일 수), 수납용량, 운반부담(Encumbrance), 회수/분해 기술·도구, 링크·이미지 참고로 덧붙임. 위키 이름이나 같은 이미지 URL이라는 이유만으로 다른 가구를 합치지 않아. Encumbrance를 실물 무게(kg)로 바꾸지 않아. 타일 ID 동일성은 B42 버전 차이 때문에 원본 이미지와 교차 검증해야 해.

## 실제 검증 범위와 한계

위키 이미지 파일은 원문 URL만 보유하며 직접 내려받거나 눈으로 1,268개를 전부 검수한 것은 아니야. 원본 PZ 대표 PNG는 기존 검수 자료에서 재사용했고, 게임 내 완전한 3D 가구 동일성이나 Forge 가구 모델 대응은 이번 작업의 승인 항목이 아니야.
