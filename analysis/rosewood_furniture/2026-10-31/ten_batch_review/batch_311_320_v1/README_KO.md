# 로즈우드 가구 29차 — 311~320 독립 시각 검수

이번 실행에서 PZ 완성형 원본 10종과 기존 소스 기반 Minecraft 비교 이미지를 각각 육안 대조했다. 기존 렌더를 재사용하며 새 Blockbench 렌더로 주장하지 않는다.

- 조건부: 314 금속 식기세척기 1종. 직육면체 금속 기기라는 구조만 유사하며 전면 패널·통풍구·손잡이·기능이 다르다.
- 보류: 311~313, 315~320 (9종). 311은 부분 JSON 렌더, 316·319는 원본 Minecraft 후보 모델 자체가 없다.
- 312는 2×1 검정 체스터필드 소파와 1블록 후보의 조립/팔걸이 차이, 320은 2×2 목재 식탁과 식기 소품의 완전 오매칭을 확인했다.
- 317·318은 같은 검은 아치형 거울이 대응되어 원본 얇은 직사각 코너 거울의 형태/방향이 일치하지 않는다.
- 실제 Forge 1.20.1 게임 설치, 충돌·기능·정확한 1:1 승인: 0종.

## 증거

- cards/: PZ 원본 PNG와 기존 Minecraft 모델 증거를 기반으로 새로 생성한 판정 카드 10장
- BATCH_311_320_MANUAL_VISUAL_REVIEW.csv: 개별 외형/재질/크기/멀티타일 관찰 및 후속 조건
- BATCH_311_320_DEFERRED_OTHER_MODS.csv: 보류 9종
- BATCH_311_320_SHA256_PROVENANCE.csv: 원본 PZ PNG, 기존 비교 카드, 새 카드 SHA-256. 과거 소스 모델 SHA는 재해시한 값이 아니다.
- MANIFEST.json, INDEX.html, ZIP: 검증 가능한 독립 결과
원본 TMX·PNG·SQLite, 다른 레인 파일, 기존 357종 누적표는 수정하지 않았다. Draft PR을 자동 병합하지 않는다.

## 개별 판정

- 311 Chair / Victorian 6 — DEFER: PZ는 빅토리아식 베이지 버튼터프팅 안락의자. 기존 Minecraft 이미지는 회색 평판/벽면 형태만 나타나 좌석·팔걸이·다리·쿠션이 확인되지 않는다. 원본 JSON 부분 렌더이므로 실제 가구 외형 비교 불가능.
- 312 Couch / Victorian C4 — DEFER: PZ는 2×1 검정 가죽 체스터필드 소파로 둥근 팔걸이와 버튼 장식이 뚜렷하다. Minecraft 후보는 각진 검정 단일 소파 블록/부분 모듈이며 원본의 2좌석 길이·팔걸이·터프팅을 재현하지 않는다.
- 313 Counter / Darkwood Floating Corner — DEFER: PZ는 나무 상판이 꺾인 짙은 갈색 벽부착 코너 수납장이다. 후보는 검은색 본체와 은색 가로 띠의 바닥형 다이너 카운터로 재질·설치 높이·색상·구조가 모두 다르다.
- 314 Dishwasher / Metal — CONDITIONAL: PZ와 Minecraft 후보 모두 회색 직육면체 식기세척기 형태여서 구조적 유사성이 있다. 그러나 PZ는 넓은 검정 전면 사각 패널과 하부 통풍구, 후보는 회색 전면도어와 상단 작은 조작부/손잡이여서 전면 구성과 비율이 다르다. 인게임 기능·충돌 미검증.
- 315 Machine / Dr. Oids Arcade — DEFER: 양쪽 모두 직립형 아케이드 캐비닛이지만 PZ의 노란 얼굴·분홍 캐릭터/문양과 후보의 초록 스페이스 인베이더 픽셀 그래픽은 완전히 다르다. 상단 장식과 조작부, 측면 디자인도 불일치한다.
- 316 Machine / PAWS Pinball — DEFER: PZ 원본은 PAWS 로고가 있는 2×1 핀볼 기계로 경사판·백박스·다리가 모두 보인다. 기존 비교 이미지에는 Minecraft 모델이 없다고 표시되어 실제 원본 모델 대조 자체가 불가능하다.
- 317 Mirror / Corner A — DEFER: PZ는 얇은 회색 테두리의 높은 직사각 평면 거울이다. 후보는 두꺼운 검은 다각형 아치 프레임으로 상단 모양·프레임 두께·재질이 다르다. 벽부착/반사 기능도 미검증.
- 318 Mirror / Corner B — DEFER: PZ 코너 B는 얇은 테두리와 푸른 유리의 직사각 거울이며 A와 배치 방향만 다르다. Minecraft 후보는 317번과 동일한 두꺼운 검은 아치 거울이라 외곽 형태와 프레임 색이 맞지 않고 A/B 방향 대응도 검증되지 않았다.
- 319 Projector / Cinema — DEFER: PZ는 좌우의 원형 필름 릴이 뚜렷한 구식 영화 영사기다. Minecraft 후보 이미지가 'MOD FURNITURE NOT VERIFIED'로 비어 있어 비교할 실제 3D 모델이 없다.
- 320 Table / Large Light — DEFER: PZ는 밝은 원목 2×2 식탁 전체와 네 다리다. Minecraft 후보는 접시·컵·수저 세팅 소품으로 식탁 본체/다리가 전혀 없다. 2×2 멀티타일 구조도 대응하지 못한다.
