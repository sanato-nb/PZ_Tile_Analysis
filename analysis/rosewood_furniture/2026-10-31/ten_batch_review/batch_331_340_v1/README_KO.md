# 로즈우드 가구 C 레인 — 331~340 독립 시각 검수

PZ 완성형 10종과 기존 소스 기반 Minecraft 비교 이미지 10종을 직접 판독했다. 새 Blockbench 렌더는 없으며 게임 설치 인증은 0건이다.

- 331~332: 낮은 2단 밝은 오픈 선반에 짙은 아카시아 상자형 선반이 잘못 대응.
- 333: 4×1 목재 3단 상점 선반을 1×1 닫힌 상자형 모델로 매칭.
- 334: 길고 가는 목재 벤치에 스툴의 평판 부분 렌더만 존재.
- 335: 1×2 금속 부검대/수도꼭지에 아카시아 유리 탁자의 평판 부분 렌더만 존재.
- 336: 참나무 아기 침대와 Decocraft crib_oak는 난간과 형태가 유사해 조건부. 상부 모빌 추가·크기·점유·기능 미검증.
- 337~338: 줄무늬/크림색 곡선 빅토리아 소파와 검정 직각 소파 오매칭.
- 339~340: 나무/금속 벽걸이 코너 상부장에 검정·은색 바닥형 다이너 카운터 오매칭.
- 조건부 1종, 보류 9종, Forge 1.20.1 설치·충돌·기능 검증 0종.

## 근거와 한계

- PZ 원본 미리보기 10개와 기존 실제 소스 기반 Minecraft 렌더 10개를 사용해 비교 JPG를 생성한다.
- baseline source_model_sha256은 이전 기록의 값으로, 이번에 모델 원본을 재해시하지 않았다.
- PZ 원본, baseline JPG, 새 JPG의 SHA-256은 이번 실행에서 파일 바이트로 계산한다.
- 부분 JSON 렌더는 완전한 외형 인증 근거로 사용하지 않는다.
- 원본 TMX·PNG·SQLite, 다른 레인 브랜치와 전체 누적 진행표는 수정하지 않는다.
- Draft PR을 자동 병합하지 않는다.

## 개별 판정

- 331 Shelves / Fossoil Low — DEFER: Handcrafted 아카시아 후보는 주황빛 닫힌 상자처럼 보이고 어두운 전면 구멍만 있으며 파란 상판·밝은 2단 오픈 선반 구조가 없음
- 332 Shelves / Generic Shop Low — DEFER: Handcrafted 아카시아 후보는 어두운 주황 갈색 상자형 렌더이며 열린 밝은 선반판 두 개가 나타나지 않음
- 333 Shelves / Greene's Grocery — DEFER: MC 1×1 상자형 아카시아 선반은 4블록 길이와 3단 선반, 측면 걸이 및 개방형 구조를 재현하지 못함
- 334 Stool / Organs — DEFER: Macaw 아카시아 스툴은 얇은 평판 일부만 렌더되어 네 다리·측면 프레임이 전혀 검증되지 않으며 색도 밝은 주황 계열
- 335 Table / Morgue — DEFER: MC 아카시아 유리 탁자 후보는 노란색 평판 부분만 보이며 금속 트레이·수도꼭지·중앙 기둥 및 1×2 길이가 없음
- 336 Bed / Oak — CONDITIONAL: Decocraft crib_oak는 밝은 목재 난간·다리의 전체적인 사물 종류와 형태가 상당히 비슷하지만 상부 모빌과 장식물이 추가되고 높이·크기 및 설치 점유가 불확실
- 337 Couch / Victorian C3 — DEFER: MC 검정 소파는 단색 검정 직각 쿠션과 블록형 형태로 줄무늬·곡선 팔걸이·목재 장식 다리가 전혀 다름
- 338 Couch / Victorian C6 — DEFER: MC 검정 직선형 소파는 색상과 등받이 곡률, 크림색 버튼 장식, 다리 구조가 전부 불일치
- 339 Counter / Oakwood Floating Corner — DEFER: Decocraft 검정·은색 줄무늬 다이너 코너 카운터는 재질·색·전면 패널이 다르고 바닥형 모델로 벽면 부착 상부 가구를 대체할 수 없음
- 340 Counter / Steel Floating Corner — DEFER: Decocraft 검정·은색 줄무늬 다이너 코너 카운터는 검정 바닥형 가구로 회색 벽걸이 코너 금속장의 색상·재질·설치 높이가 다름
