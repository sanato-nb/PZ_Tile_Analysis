# 로즈우드 가구 C 레인 — 301~310 독립 시각 검수

PZ 완성 스프라이트 10종과 기존 소스 기반 Minecraft 렌더 비교 JPG 10종을 직접 대조했다. 새 Blockbench 렌더는 없으며 인게임 1:1 인증은 0건이다.

- 301·302: 투명 유리 진열대와 불투명 다이너/아카시아 카운터 오매칭.
- 303·304: 나무 패널과 상판 색·재질이 기존 카운터 후보와 다름.
- 305·306: 오픈형 벽 선반 구조와 기존 상자형 선반 렌더 불일치.
- 307: 2×1 목재 탁자에 식기 세팅 소품만 매칭.
- 308: 검증된 MC 볼링 기계 모델 없음.
- 309: 볼링 금속 랙에 의류 진열대가 잘못 매칭.
- 310: 곡선 흔들의자에 회색 평판 부분 JSON 렌더가 매칭.
- 조건부 0종, 보류 10종, 실제 Forge 1.20.1 설치·충돌·기능 검증 0종.

## 근거

- 기존 PZ 원본 미리보기 10장, 기존 Minecraft 소스 렌더 10장으로 새 비교 JPG 10장 제작.
- CSV의 source_model_sha256_from_baseline은 이전 기록에서 가져온 값이며 이번에 모델 원본을 재해시하지 않았다.
- 이미지 원본 및 비교 JPG SHA-256을 실제 파일 바이트로 계산한다.
- 다른 레인 브랜치, 원본 TMX·PNG·SQLite 및 전체 누적 진행표는 변경하지 않는다.
- Draft PR을 자동 병합하지 않는다.

## 개별 판정

- 301 Counter / Glass Corner Display — DEFER: MC는 검정 본체에 은색 수평 줄무늬만 있는 불투명 다이너 카운터로 투명 유리와 열린 진열 공간이 없음
- 302 Counter / Glass Theater — DEFER: MC 아카시아 카운터는 회갈색 불투명 몸체와 주황색 상판으로 투명 유리·전면 개구부가 없음
- 303 Counter / Pie Store Corner — DEFER: MC 검정 금속 다이너 코너 카운터는 재질과 검정/은색 띠가 다르고 나무 상판과 크림색 패널이 없음
- 304 Counter / Seahorse Coffee — DEFER: MC 아카시아 카운터는 밝은 주황 상판과 회색/갈색 거친 나무무늬 몸체로 색상·표면 질감이 다름
- 305 Shelves / Wooden Shop — DEFER: MC 짙은 갈색 상자형 렌더로 전면 2개 선반판과 개방된 구조가 확인되지 않음
- 306 Shelves / Zippee Low Wall — DEFER: MC는 주황/갈색 나무 질감의 단단한 상자형 선반 렌더로 흰색·빨간 테두리 및 얇은 판 구조가 없음
- 307 Table / Exceptional Large — DEFER: MC 후보는 접시·컵·포크·나이프 테이블 세팅 소품뿐이며 탁자 본체·다리·2×1 점유가 없음
- 308 Bowling Machine /  — DEFER: MC 비교 화면에 검증된 실제 모드 모델이 없어 3D 비교 자체 불가
- 309 Bowling Rack /  — DEFER: MC는 목재 선반·옷걸이·다색 의류가 달린 큰 의류 진열대라 사물 용도와 형상이 다름
- 310 Chair / Rocking 2 — DEFER: MC 후보는 회색 평판만 보이는 부분 JSON 렌더로 의자 좌석·팔걸이·곡선 흔들다리 전혀 확인 불가
