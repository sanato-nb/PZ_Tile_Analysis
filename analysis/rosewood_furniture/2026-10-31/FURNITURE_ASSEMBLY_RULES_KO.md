# 로즈우드 가구 다중 타일 조립 안전 규칙 (2026-10-31)

사용자 지적대로 **타일 1개 ≠ 완성 가구 1개**다. 기존 `ALL_FURNITURE_TILE_IDS.csv`의 4,248종은 각 개별 스프라이트 ID, `FURNITURE_PLACEMENTS.csv.gz`의 94,073건은 TMX GID 배치 기록이다. 이 수치를 가구 물체 개수나 Minecraft에 놓을 가구 블록 개수로 사용하면 안 된다.

## 원본 .tiles 속성으로 확인한 구체적 근거

- `furniture_bedding_01/40..55` = `CustomName=Bed, GroupName=Large Oak`. 방향 E/S/W/N 각각 4개씩, `SpriteGridPos`가 `(0,0),(1,0),(0,1),(1,1)`인 **2×2칸 가구 템플릿 네 방향**. **16개 타일 ID → 네 방향 × 한 침대 종류**, 실제 배치 개수는 TMX에서 조립해 계산해야 한다.
- `furniture_seating_indoor_02/32..39` = `CustomName=Couch, GroupName=Blue Rattan`. 각 방향의 `SpriteGridPos`에 근거한 **2칸짜리 소파 템플릿**(가로/세로는 방향 따라 바뀜). 8개 ID가 소파 8개를 의미하지 않는다.
- `furniture_shelving_01/24..27` = `CustomName=Shelves, GroupName=Large Metal`. E향은 `(0,1),(0,0)`, S향은 `(0,0),(1,0)`으로 표시됨. **4개 ID는 두 방향 × 두 부품**.

## 이번에 별도로 생성한 자동 조립 검토 목록

기존 로즈우드 4,248종 중 `SpriteGridPos`가 있는 ID **1,072종**, 없는 ID **3,176종**. 원본 타일셋명+CustomName+GroupName+Facing별로 **435개 방향별 템플릿 후보**를 기록했다.

그중 사용된 ID의 격자 좌표가 둘 이상이고 완전한 직사각형으로 나타나는 템플릿 414개, 불완전하여 추가 검수가 필요한 템플릿 18개다. **이 수치는 로즈우드에 배치된 완성 가구 개수가 아니라 '원본 타일 유형별 조립 템플릿 후보'의 개수**다.

`SpriteGridPos`가 없는 3,176종은 단일 블록 가구임이 증명된 것이 아니다. 이름·방향이 다른 부품, 단일 스프라이트, 구조물과 장식이 섞여 있으므로 최종 판정 보류한다.

## Minecraft 변환 시 반드시 적용할 규칙

1. **종류 구분:** 타일셋+원본 CustomName/GroupName+Facing 조합과 SpriteGridPos로 가능한 가구 유형·방향별 템플릿을 제안하되, 동일 이름만으로 모든 가구를 하나로 합치지 않는다.
2. **실제 인스턴스 복원:** TMX에서 같은 층과 호환되는 레이어, 이웃 칸, 완전한 SpriteGridPos 집합을 검사해 **실제 배치된 물체 하나**로 묶는다. 층·건물·방 경계를 넘겨 멀리 떨어진 부품을 합치지 않는다.
3. **좌표 검증:** SpriteGridPos는 원본 스프라이트 좌표 단서다. 이 값이 TMX의 x,y 오프셋과 일치한다는 추측은 한두 사례로 확정하지 말고, 여러 방향의 실제 원본 이미지와 배치를 대조한다.
4. **불완전 가구:** 2칸짜리에서 부품 하나만 보이면 1칸짜리 가구로 축소하거나 다른 가구를 자동 연결하지 않는다. **PARTIAL/AMBIGUOUS**로 기록하고 가림, 겹침, 경계 밖/다른 레이어 가능성을 검사한다.
5. **방향:** E/S/W/N은 별도 가구 4개가 아니라 대체로 같은 외형 종류의 회전 변형일 수 있다. 마인크래프트 `facing` 속성과 크기를 확인하고 **물체 인스턴스당 대응 모드 가구를 한 번만 배치**한다.
6. **가구 연속체:** 싱크대·주방 카운터·책장처럼 여러 완제품을 나란히 붙이는 경우는 '여러 개의 개별 가구가 이어진 것'인지 '하나의 멀티타일 물체'인지 구분해야 한다.
7. **충돌/기능:** 픽셀이 없는 부품, 물리 속성이 있는 부품은 무조건 공기로 지우지 않는다. 가구 완성 단위의 충돌·수납·조명을 별도로 매핑한다.
8. **출처/판정 보존:** 사용자 수동 판정·기존 이미지 잠정 판정·원본 .tiles 판정은 다른 열에 남긴다. 완성 가구 ID가 검증될 때까지 기존 94,073개 GID 배치와 4,248개 고유 키를 수정하지 않는다.
