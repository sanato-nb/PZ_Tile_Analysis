# 로즈우드 가구 중복 제외 — 모델/종류 집계

기준: 로즈우드 중심 시가지 TMX X30–33, Y43–48.

- 위치별 가구 기본 집계: 15,957개 잠정 → 엄격한 동일 객체 레이어 중복 8건 삭제 → **15,949개** 잠정.
- 원본 CustomName+GroupName+원본 타일셋(방향 무시)으로 구별한 모델 키: 기본 가구 **271종**, 이름 있는 특수 가구 **91종**.
- 원본 타일셋을 달리하지만 이름·그룹이 동일한 항목도 하나로 보는 **중복 없는 명명 스타일 조합: 357종**.
- 더 넓은 이름만 비교하면 **79개 이름**. 같은 이름의 모델·재질 변형이 섞이므로 79종만이라고 하면 스타일 구분을 잃는다.
- 원본 이름이 없는 기본 가구 위치 후보 **1,221건**, 출처별 임시 자산 키 **97종**은 357종에 포함하지 않음. 정체 확인까지 보류.
- 이름이 있는 가구 후보 위치 집계: **16,039개** (기본 14,728 + 특수 1,311). 이것은 종류 수가 아닌 배치 건수.
- **이름/스타일이 같아도 서로 다른 좌표에 놓인 가구는 각각 1개씩** 배치 인벤토리에 보존한다.
- 동일 좌표에서 다른 자산 ID인 물체 후보는 기본 가구 중심 **415개 충돌 그룹**이 있어 확정 중복이라고 주장하지 않고 검수 보류한다.

모델별 `FURNITURE_MODELS_DEDUP_NAME_GROUP.csv`는 357행이며 원본 타일셋이 달라도 이름·그룹이 같은 5건의 중복 모델 키가 합쳐져 있다. `FURNITURE_NAMES_DEDUP.csv`는 79개 원본 CustomName 목록.

**주의:** 이름이 같아도 실제 디자인이 다른 경우가 있으므로 이 357종은 이름 기준 통합값이며 게임 이미지 기반 최종 모델 인증은 아니다.
