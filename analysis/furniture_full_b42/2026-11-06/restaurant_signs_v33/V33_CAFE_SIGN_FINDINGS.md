# 식당 간판 56·57번 배치 대조

원본 PNG에서 두 조각을 읽으면 빨간색 Cafe 글자가 이어진다. 각 타일의 원본은 newtiledefinitions.tiles이고, CustomName=Sign, MoveType=WallObject, Facing=S, attachedN 속성이 공통이다. SpriteGridPos는 56번이 (0,0), 57번이 (1,0)이다.

저장소 TMX 4,914개 타일 레이어에서 같은 아틀라스의 40–57번이 16개 맵에 100회 등장했다. 그중 56번 3회, 57번 2회다. 아래는 해당 원본 TMX의 level과 실제 이웃 칸 GID를 다시 읽은 결과다. 좌표는 파일 내부 타일 좌표다.

| TMX | level / 레이어 | 56번 | 57번 | 두 타일의 배치 |
|---|---|---|---|---|
| 51_21.tmx | 0 / Vegetation | (37,79) | (38,79) | 원본 그리드와 같은 순서로 바로 이웃한다. |
| 59_1.tmx | 0 / FloorOverlay | (3,211) | (5,211) | 사이 (4,211)의 해당 레이어 GID는 0이다. |
| 52_8.tmx | 0 / FloorOverlay6 | (220,102) | 해당 파일에 없음 | 바로 오른쪽은 lighting_outdoor_01/26이다. |

시각 판독, 원본 속성, 인접 배치가 일치하므로 56·57번을 남향 Cafe 간판 조합 후보로 구분한다. 두 타일이 항상 함께 배치되는지, 하나의 아이템으로 회수되는지, 동향 대응 타일이 있는지는 이 근거로 확정할 수 없다. 공식 가구 수와 해결된 경고 수에는 가산하지 않았다.
