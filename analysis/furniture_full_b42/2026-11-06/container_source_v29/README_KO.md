기준: 성공한 v28 SQLite ZIP을 **새 파일로 복제**했고 기존 원본 테이블과 이전 증거는 건드리지 않았습니다.

- 그룹별 분류: \`{"CONSISTENT_NONEMPTY_SOURCE_FIELDS": 51, "DIRECTIONAL_SOURCE_FIELD_MISSING": 12, "NO_ORIGINAL_STORAGE_FIELDS": 211}\`.

- 실제 런타임 오브젝트와 방향별 동일성 인증 0건, 신규 이미지 검수 0건. 게임 내부 SpriteGrid/Container 규칙의 독립 증거가 필요합니다.
