# v4 실제 원본 이미지 관찰 11그룹 + 전체 방향·부품 원본 정보 감사

기존 58개 접촉시트는 실제 PZ 원본 PNG를 가져와 제작했으며, 이번 문서는 그중 **11개 그룹의 이미지를 직접 열람해 비교**하고 별도 관찰 결과를 기록한 문서야.

## 357개 위키 항목에 기록된 방향·조립 속성

- Wiki 원본 행: 357개 (58개 TileDef 그룹)
- Wiki 이름 계열: 66개 (50개는 기본 이름 하나, 8개는 서로 다른 기본 이름으로 분리)
- 원본 Facing이 둘 이상인 이름 계열: 5개
- 원본 Facing이 하나뿐인 이름 계열: 18개
- 원본 Facing 값이 기록되지 않은 이름 계열: 43개

**Facing이 없는 43계열은 단순 그림만 보고 방향을 추정해 자동 합치지 않아.** 그리고 원본에 Facing이 둘 이상 있어도 정확한 게임 가구 동일성은 별도 증거가 필요해.

## 검수 파일

- V4_FAMILY_DIRECTION_SOURCE_AUDIT_66.csv — 66 계열의 원본 Facing 분포 및 멀티타일 조립 근거

원본 가구의 실제 Moveable 객체 정체 확정과 마크 Entity/Block 구현 선택은 진행하지 않았어.
