# Project Zomboid B42 가구 원본 방향 비교 v24 — 신규 80그룹·160방향·466원본 픽셀

v23 전체 SQLite의 원본 수집 정보와 v21~v23 시각 검수 이력을 보존하면서 v24 원본 PNG 방향 비교를 추가했습니다.
v21~v23에서 시각 검수한 고유 원본 200그룹을 제외하고 새 80그룹을 선정하여 두 방향씩 총 160개 기하 후보의 원본 그리드를 직접 비교했습니다.
접촉시트 8장, 원본 PNG 40개 아틀라스, 원본 스프라이트 부품 466개의 실제 픽셀 해시를 기록했습니다.
누적 다중 타일 기하 후보 이미지 검수 480/820(58.54%). 남은 340개 방향별 이미지 검수 큐를 생성했습니다.
고유 346그룹 중 280그룹에서 최소 한 방향을 직접 보았고, 274개 다방향 후보 그룹 중 200그룹에서 두 방향을 직접 비교했습니다.
이번 v24 접촉시트에는 가구 후보 이외에 다수의 간판·회화·표지판이 섞여 있어 외형만 광의 분류하고 원본 후보 원장에서 자동 삭제하지 않았습니다.
SpriteGridPos 그리드 및 유사 이미지가 게임에서 실제 하나의 가구 오브젝트이거나 모든 방향에서 동일한 객체임을 증명하지 않습니다.
위키는 오래됐거나 불완전할 수 있는 참고 자료이고 TileDef와 원본 PNG를 우선했습니다.
기존 원본 경고 474건, PNG 아틀라스 미연결 23그룹 및 이전 Work 보고분은 그대로 보존·구분했습니다.
