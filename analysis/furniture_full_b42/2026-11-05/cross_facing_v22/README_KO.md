# B42 원본 가구 방향 비교 v22 — 60그룹, 두 방향씩 실제 원본 타일 그리드 직접 검수

v21 전체 SQLite를 복제해 원본 TileDef·위키 참조·대표 이미지 검수 940그룹·부품 그리드 80건·기존 경고 474건·PNG 미연결 23건을 보존.
v21 시각 검수 그룹과 전혀 겹치지 않는 원본 그룹 60개에서 2개 Facing씩 골라 원본 PNG **258개 셀**의 실제 픽셀/PNG SHA를 기록했습니다.
6개 접촉 시트에서 60그룹/120방향을 각각 두 방향 좌표 그리드로 **직접 나란히 관찰**, 동일 넓은 디자인 계열과 방향별 표현 차이를 기록했습니다.
E와 S처럼 방향별 원본 SpriteGridPos 폭/높이가 교환되는 사례를 원본 값으로 따로 계산했으며, 위키 이름이나 좌표만으로 같은 가구라는 결론을 내리지 않았습니다.
기존 v21 그리드 이미지 검수 80건 + 신규 방향별 이미지 검수 120건 = **200 / 820 = 24.39%**. 이후 620개 방향별 기하 후보가 남습니다.
새 60개는 위키 연결이 있는 원본 그룹이지만, **위키는 최신성·완전성이 검증되지 않은 참고 자료**입니다.
원본 타일 PNG 배치 그림은 게임 자체의 정밀 아이소메트릭 장면 합성이나 런타임 오브젝트 동일성 검증이 아닙니다. 공식 인증 0.
