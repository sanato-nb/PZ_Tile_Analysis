# Project Zomboid B42 전체 가구 원장 v6 — 원본 이미지 71그룹 비교 도감

71개 그룹의 위키 항목이 참조하는 **실제 Project Zomboid 원본 Tiles/2x PNG**를 비교해, 동일 TileSet/LocalID는 한 번만 표시하고 연결된 모든 위키 카테고리·수납 용량을 기록했어.

### 해석 원칙

- 동일한 원본 스프라이트 집합을 참조하는 위키 행은 원본 이미지 중복 기록이야. 실제 게임 Moveable 객체의 고유 ID를 확정했다는 뜻은 아냐.
- 한쪽 카테고리의 수납 용량이 공란이어도 0으로 바꾸지 않아. 같은 그림을 참조하는 Storage 항목의 수납 값이 있다면 원문 출처와 함께 보존해.
- 같은 원본 ID에 서로 다른 이름이 붙은 6건은 원본 메타데이터와 실제 그림으로 추가 판단해야 해. 이 도감은 의미 자동 병합용이 아니야.
