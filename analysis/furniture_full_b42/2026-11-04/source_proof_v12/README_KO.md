# B42 가구 원본 근거 검증 v12

v11 SQLite를 복제하여 기존 테이블을 변경하거나 삭제하지 않고 6개의 v12 증거 테이블을 추가함.

* v11 원본 경고 474건: 각 타일 원본 SpriteGridPos/Facing/Wiki 앵커/수납 원문으로 독립 재계산했으며 모두 동일. 경고는 미해결 상태 유지.
* 8,219개 source_key와 좌표는 원본 타일별로 연결. 각각 정렬한 ID/좌표 목록 zip 금지. 좌표가 일부라도 존재하면 해당 좌표의 상대 위치를 보존, 가구 동일성은 확정하지 않음.
* 직사각형 843, 방향별 후보 3,840은 실제 게임 가구 종류 확정이 아님.
* 위키 미연결 11건 새 타일 연결 0. 이름만 같은 그룹 병합 0.
* 129개 이미지 검수 참조는 DB에 저장된 검수 범위 기록. 게임 오브젝트 인증 아님.
* Work 107그룹/574타일은 이미지 열람 보고만 확인; 개별 타일 리뷰의 GitHub/SQLite 저장 증거 부재로 IMPORT=0. 가짜 리뷰행을 생성하지 않음.
* 원본 수납 값은 타일별 보존, 용량 합산 없음. Lua loot/TMX 인스턴스/Minecraft 구현 미선택.
