# 가구 v7: 중복 위키 항목의 속성 보존과 충돌 분리

v6 커밋 `85c3252fa01d12f4637d44d01430130e9760f785`의 CSV 5개를 실제로 읽고 교차 검증했다. 이번 결과는 **추가 관계/속성 감사 자료**이며 전체 가구 DB 대체본이 아니다. 원본 이미지 신규 열람은 0건이다.

## 결과

| 항목 | 수량 |
|---|---:|
| 대조한 원본 그룹 | 71 |
| 정확히 같은 타일 집합을 참조하는 위키 쌍 | 73 |
| 같은 기본 이름 + 같은 타일 집합 | 67 |
| 다른 이름 + 같은 타일 집합(건조대) | 5 |
| 이름·종류·속성 충돌, 별도 유지 | 1 |
| 보존한 위키 행 / 타일 참조 | 146 / 178 |
| 위키 속성 필드 감사 | 365 |
| 양쪽 일치 / 한쪽만 기록 / 양쪽 미기록 / 충돌 | 144 / 66 / 153 / 2 |

73은 가구 종류 수가 아니다. 72쌍은 동일 타일 집합을 조회하는 묶음으로 표시할 수 있지만 게임 객체 동일성, 외형 동일성, 다칸 조립 확정을 뜻하지 않는다. 충돌 쌍은 2개 조회 ID로 유지하여 전체 조회 ID는 74개다. 모든 위키 행은 삭제 없이 남는다.

## 구체적으로 수정한 처리

- `White Fossoil Floor`(PZW-0789)와 `Out of Gas Sign`(PZW-0968)은 `location_shop_fossoil_01/38`을 함께 참조하지만 크기는 1/2, 운반부담은 1.0/5.0이다. 기존 v6의 이름 충돌에 수치 충돌 증거를 추가했다. 어느 이름이 맞는지 결정하지 않으며, 두 항목의 속성을 자동으로 합쳐 쓰지 않는다.
- Fancy Floating Counter(`/24`)와 Birch Floating Counter(`/26`)는 서로 다른 타일 집합의 두 묶음으로 유지한다. 같은 원본 그룹이라는 이유로 합치지 않는다.
- 한 위키 분류에만 수납 용량이 있으면 원문 출처와 함께 조회한다. 다른 분류의 빈칸을 0이나 수납 불가로 해석하지 않는다. TileDef 용량과 위키 용량을 혼합하지 않는다.
- 타일별 container/capacity/Facing/SpriteGridPos는 178개 참조 그대로 보존한다. 다칸 타일 용량을 더해 가구 용량으로 만들지 않는다.

## 파일과 재현

`V7_ALIAS_POLICY.csv`: 73묶음 처리 정책.
`V7_FIELD_RESOLUTION.csv`: 365개 필드, 원문 값과 위키 ID/문서 출처.
`V7_LISTING_MEMBERSHIP.csv`: 원문 146행의 조회 ID.
`V7_PENDING_VISUAL_REVIEW.csv`: 아직 추가 열람하지 않은 원본 64그룹의 이미지 경로.
`V7_PRESERVED_WIKI_PROPERTIES.csv`, `V7_PRESERVED_TILE_REFERENCES.csv`: 입력의 전체 행·값 보존.
`ALIAS_POLICY_OVERLAY_V7.sql`: 6개 테이블과 1개 조회 뷰를 복원하는 SQL. 전체 v6 DB가 아니다.

저장소 루트에서 아래 명령으로 CSV와 SQLite를 재생성한다. 출력 경로는 새 폴더여야 한다.

```bash
python scripts/build_b42_alias_policy_v7.py --input analysis/furniture_full_b42/2026-11-04/shared_wiki_v6 --output /tmp/pz_alias_v7
```

SQL을 새 SQLite에 실행해도 동일한 추가 감사 DB를 복원할 수 있다. 원본 v6 DB를 이 파일로 대체하면 안 된다. 이번 작업에서는 v6 SQLite 본체에 병합하지 않았다.

## 검증 및 정확한 진행도

73개의 타일 집합과 146행의 소속을 178개 개별 타일 참조에서 재검증했다. 중복/누락 없음, 동일 원본 키의 TileDef 속성 일치, SQLite integrity_check=ok, SQL 복원 후 전행·전값 동일을 확인했다. 충돌 값 조회 차단, Fancy/Birch 분리, 원문 146행 조회 보존도 검사했다.

이번 신규 이미지 관찰 0. 이전 기록 기준 시각 검수 65/129 유지, 남은 중복 그룹 64, 추가 원본 963그룹의 시각 검수 진행도는 늘리지 않았다. 이미지 다운로드가 되지 않아 텍스트 근거로 가능한 속성 감사를 수행했다. 게임 객체 정체 인증과 마인크래프트 구현은 미수행이다.
