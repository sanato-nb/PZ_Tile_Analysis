# B42 source-only v15 — 원본 타일 160개의 실제 이미지 형태 관찰

v14 접촉시트 4장을 직접 열어 보고 총 160개의 단일 스프라이트 셀에 대한 넓은 시각적 유형을 기록했습니다.
원본 PNG 픽셀 SHA256 및 접촉시트 SHA256에 행별로 연결하여 160개 개별 시각 검수 레코드를 보존했습니다.
가구 외에 간판/포스터/자연물/건축 자재/설치물도 섞여 있으므로 '963개 미연결 = 963종 가구'로 보지 않습니다.
시각 유형은 텍스트/원본 이미지의 단일 타일에 근거한 **잠정 광의 분류**이며 정확한 게임 이름, 동일 가구의 다른 방향, 조립/런타임 정체를 뜻하지 않습니다.
160/963은 한 셀의 시각적 확인 범위일 뿐, 개별 가구 전체의 확인율이 아닙니다.
기존 Work에서 보고한 107그룹/574타일은 행별 증거가 없어서 이전과 같이 신규 160 검수 결과로 합산하지 않았습니다.
위키는 오래되거나 누락될 수 있는 보조자료, 원본 TileDef/PNG 우선. 기존 474경고 전부 미해결.
