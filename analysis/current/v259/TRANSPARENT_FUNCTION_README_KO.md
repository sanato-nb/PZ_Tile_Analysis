# v259 투명 PNG 셀과 기능 속성 교차 검수

원본 논리 셀 중 알파가 완전 투명한 13,706개를 기준으로 조사했다.

- 원본 속성 1개 이상: 105개
- 충돌/물리/벽·문·창 구조 힌트: 23개
- 설치 제한 등 넓은 동작 힌트: 36개
- 이름 힌트: 53개

원본 .tiles 속성은 동작 가능성을 나타내는 단서이며, 실제 게임 엔진의 충돌/상호작용이 발생함을 직접 증명하지 않는다.
투명한 슬롯이 게임에서 쓰이는지는 TMX 배치와 엔진 동작을 별도로 검증해야 한다.
TRANSPARENT_FUNCTION_CANDIDATES.csv와 TRANSPARENT_FUNCTION_AUDIT.json에 세부 결과를 기록했다.
기존 원본과 마스터 DB는 수정하지 않았다.
