# v109 독립 증거 적격성 감사 — D 실제 사용 위치 필수 (비계상)

검토일: 2026-10-26. 대상: `work/v109-visual-20261026`의 `checkpoints/v109_preview/EVIDENCE_MANIFEST.json`, `review_notes_*.psv`, 접촉 검수판 8장과 `d_generic_1/22` 개별 A/B/C/D 합본.

## 실제 수행

- 원본 PNG/TMX에서 만들어진 v109 A/B/C/D **접촉판 8장을 모두 직접 열어 시각적으로 비교**했다. `d_generic_1/22` 개별 A/B/C/D 합본도 확대 확인했다. 이는 **이미 생성된 증거에 대한 독립 재검수**이지 신규 원본 렌더링 작업은 아니다.
- 매니페스트의 **48행**, 고유 `(tile_set_locator, local_id)` **48키**, 판독 PSV **48행**을 인덱스별 대조했다. 키 중복 0, 판독 메모 후보 40·보류 8. 기존 통합 DB와의 중복 여부는 이번에 직접 복원해 검사하지 않았다.
- 다른 실제 TMX 사용 위치 D: **1/48**. **47/48은 D가 실제 다른 장소 이미지가 아닌 미확보 안내판**이다. 단 하나인 `d_generic_1/22`의 D는 `31_45.tmx` (-1층, 149,71)로, 원위치는 (-1층, 144,61). 그러나 A가 투명하게 보이고 **B-C 변화 0픽셀**이므로 사물 정체 판독에 기여하지 않는다.
- `carpentry_02/112`도 A 투명·B-C 0픽셀, D 없음. `floors_rugs_01/128` 및 `/129`는 B-C 변화 291·270픽셀로 약하다. 전부 잠정/보류 구분을 유지한다.

## 엄격한 사용자 요구사항에 따른 결론

**A 원본 + B 같은 층 5×5 + C 단일 배치 제거 + D 다른 실제 사용 위치를 모두 확보하고, 대상 타일의 배치 기여까지 관찰 가능한 신규 키: 0종.**

v109 증거 48종을 이미지 A/B/C 기반 예비 판독으로 보존할 수는 있지만, **실제 D를 요구하는 관찰 완료 기준으로 48종을 신규 누적 계상해서는 안 된다.** 47종은 실제 D가 없고, 나머지 1종은 투명/차이 0이기 때문이다. 기존 v108 이하 기록을 소급 변경하지는 않는다. 새 기록을 통합하려면 D 예외를 명시적으로 승인받거나 다른 원본 TMX/공식 TileZed에서 재검증해야 한다.

## 검증 범위 및 미수행 항목

매니페스트 고유 키, D 존재 여부, 좌표, 픽셀 변화 기록과 PSV 행을 대조했다. 접촉판 8장과 개별 1장을 실제 열었다. **원본 PNG/TMX 바이너리 SHA-256 재계산, SQLite 물리 복원·`integrity_check`, JPEG 240장 전수 디코딩, TileZed 공식 Local ID 검증은 이번 감사에서 수행하지 않았다.** 따라서 신규 SQLite·CSV·정체 인증을 만들지 않았고, `PROJECT_STATE.json`의 v108 누적 수치를 변경하지 않았다.
